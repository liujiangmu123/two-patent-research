# 两项目分析与研究安排

日期：2026-10-05。范围：现有资料审阅、版本归档、研究缺口识别与下一阶段任务。以下结论以仓库内证据为边界，不把文件完整度当作实物验证或授权结论。

## 刘智远专利

历史 A–E 对应角钢高斯/激光联合反演、规范逆向设计与振动标定、InSAR形变解耦、补测航线、视频振型识别。2026-10-03工程包将本轮重点收敛为“基于可辨识性门控的输电塔角钢截面联合反演与承载能力评估”。五项历史草稿保留为研究背景；不得把所有历史特征直接合并成一项已实现发明。

该重点方向的技术链是：共享节点与有限厚度角钢模型 → 观测拟合并保留同宽异厚歧义 → 对不同验算判定构造联合候选对 → 用噪声归一化分离度选择补测 → 遥测不足时转局部测厚 → 回灌并保留未决状态。研究价值集中在“歧义如何影响工程判定、哪些测量真正消除判定分歧”，而不只是生成高斯可视化。

证据入口：`工程实现_20261003/docs/implementation_status.md`、`docs/patent_scope_and_evidence.md`、`validation/AUDIT.md`、`software/tests/test_core.py`、`patent/03_权利要求书.md`。已有审计记录称23项原型测试通过，A01–A08覆盖越库、矛盾、强先验、空观测、缺证据、联合候选、重复来源和单候选来源问题；本次重跑结果单独记录。

缺口：输入仍依赖人工关联和固定标定；激光足迹是简化误差模型；FE是轴向铰接桁架筛查；干扰参数联合优化、连接偏心和完整承载验算、真实传感器接口、实塔覆盖率均未完成。权利要求中完整物理观测、干扰消除及工程输入区间传播等特征应逐项对照充分公开及实现证据。

优先任务：

1. 固定实际传感器能力，建立原图/点云/测厚的来源、坐标、单位与关联适配器；验收要求是原始数据到输入因子的可追溯记录及重复来源处理。
2. 制作同宽异厚角钢样件，独立校准后盲测；输出错误确定率、候选覆盖和遥测转测厚判据，不用合成权重代替实测准确率。
3. 核对梁/连接/荷载模型适用性；记录偏心、边界与材料未知时的未决输出，并与现有轴向模型对照。
4. 形成“独权每一特征—说明书段落—代码—试验—缺口”对照表；与历史A/D及已有反射器申请逐项区分。

版本核对：总览显示P1文字收尾、P5首版完成，P2/P3/P4尚未完整；P2进度实际已记录容腔斜率复核修正。2026-10-03工程完善包已包含尾座121个、试验台V3 428个几何零件实例及模型/STEP/BOM，但明确未制造放行、未完成专利定稿。零件实例数不能作为采购物料数量。

证据入口：`00_专利组合总览.md`、各件`10_审查与迭代/进度.md`、P1`未关闭问题清单.md`、`11_工程完善_20261003/07_交付/工程阶段说明与验收目标.txt`、`06_仿真/FEM/网格比较与适用范围.json`。
