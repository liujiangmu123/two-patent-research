# 地面标定与角钢样件套件结构设计

设计编号 LZT CAL 01。该结构服务于现成无人机加地面工作站方案，用于近距几何标定、同宽异厚对照采集和现场测厚流程演练。它不是飞行挂架，也不是承载试验加载装置。参数见 `design_parameters.json`，计算见 `calculations.json`，CAD 执行清单见 `cad_jobs.json`。

## 构成与操作

底座为650×500 mm矩形框，两根立柱位于x=±220 mm、y=230 mm的后横管上，立柱高650 mm，斜撑从前横管向立柱顶部连接。顶部横管净长400 mm，连接立柱内侧面。40×40×2 mm铝合金方管用于主框，20×20×2 mm方管用于斜撑和短悬臂；采购截面和连接件最终需核对。四个M8调平脚、前侧机械锁固的3 kg配重和独立系固点构成地面支承；只有实测质量与重心已满足全部稳定假设时，才允许省去配重。孔、槽和快拆件均为套件自身接口，不宣称与未知无人机兼容。

两根150 mm长角钢样件的名义截面为L100×8与L100×10，采用独立可调夹座安装，在观测中保留内外肢面、厚度边面和端面。样件编码C08/C10只是名义标签，实际厚度必须多点测量并记录；标准热轧角钢的圆角、实际宽度、表面涂层和截面公差需另登记。原型中的理想无圆角截面不能自动成为实物真值。

样件轴线名义起点为(-170,120,180)与(170,120,400) mm；右侧样件绕轴旋转180°以朝向框架内侧。各夹座由150 mm短悬臂承托。主框采用螺栓和角连接片装配，薄壁管的贯穿紧固位置配置压缩套管，不能直接将壁厚2 mm方管当成实心螺纹座。实际孔距、套管和连接片选型需随供应件冻结。样件和参考靶装配后仍须执行干涉与工具可达性验证。

四个哑光参考靶的名义中心错层布置，避免全部共面。实际中心坐标、距离和校准不确定度经独立仪器测定后写入控制点记录，软件使用这些实测值。装配尺寸仅用于加工与定位，不能将切管长度或CAD坐标作为零误差控制点。

所有夹座具有2 mm隔离垫，避免直接压伤角钢和异种金属长期接触。样件压紧区避开需要观察的端边及测厚区，正面与背面可从多个方向访问。夹紧螺栓扭矩由选定连接件厂家与夹紧复现试验确定，不虚构统一额定扭矩。

## 力学和环境边界

计算采用铝合金E=69 GPa、密度2700 kg/m³，钢密度7850 kg/m³作为设计假设；两块铝夹座板和配重托盘计入1.5 kg连接件预算，调平脚及靶/靶架另留0.9 kg预算。风载模型为0.5ρv²CdA，迎风面积0.14 m²、Cd=1.5、阵风系数2；所有风力保守施加于0.70 m高度。最低实际总质量7 kg、重心平面偏移不超过50 mm时，在5 m/s条件下计算抗倾覆系数需≥2。抗倾覆力臂按调平脚中心y=±230 mm减去重心偏移计算。实际质量、重心和地面支承必须核验，否则该计算不能使用。

短臂从立柱前表面y=210 mm向前伸出，样件支臂长150 mm；参考靶支臂依靶位置采用130、130、100、70 mm。斜撑置于立柱外侧x=±250 mm，中心线由(±250,-230,50)连接至(±250,230,670) mm，端部通过连接片固定；名义中心线长度不是最终斜切面下料尺寸，须随CAD端接和采购连接片核定。配重名义中心位于(0,-200,55.25) mm，钢块名义260×60×24.5 mm，放在底座前管上方的300×110×3 mm铝托盘内。托盘贯穿连接须有压缩套管，配重用金属压带锁固，不能只靠自重和摩擦。没有配重时，按本版质量分布估计的重心前后偏移大于50 mm，不能直接按声明边界使用。

立柱位移按两个相同40×40×2 mm方管分担风力的悬臂上界模型计算，斜撑改善不计入。这是初步手算模型，连接滑移、底座柔性、热变形、地面不平整与振动仍需实物测试。无加载装置或实测记录时，不称作已完成有限元或现场稳定性验证。

样件支臂另按3 kg载荷、150 mm前伸和50 mm横向偏心计算弯曲与闭口薄管扭转；泊松比0.33为初步假设。弯曲位移与100 mm尺度上的扭转位移保守相加，详见计算JSON；螺栓/夹座滑移、壁板局部变形仍须台架测定。低位参考靶采用以x=±220 mm为轴的支臂，再通过30 mm横向靶架偏置到x=±250 mm，不能把低位靶位置直接当作管轴与立柱端接。

标定采集要求风速≤5 m/s并保持套件固定；超过条件暂停精度标定，使用系固/配重也不自动扩大精度边界。铝框650 mm尺度在3 K温差下热伸长约46 µm，温差增大需重新核验坐标。采集前后各测一次关键控制距离和水平度，出现位移、夹座滑动或支承沉降时作废本次标定。

## 装配与制造顺序

1. 按实际采购截面核对切管长度、连接片及紧固件，加工后清除毛刺。
2. 在平整平台装配底座并检查对角线，安装调平脚及承压垫。
3. 装配立柱、横梁和后斜撑，检查所有连接区不遮挡观测区。
4. 安装样件夹座、隔离垫和靶架，进行夹紧滑移及重复装夹测试。
5. 记录实际总质量、重心、参考靶坐标与样件截面，建立序列号。
6. 完成静态侧向拉力、支承稳定、重复装夹和温度复测，留存记录后开放标定使用。

## FreeCAD MCP 状态

本项目AGENTS.md规定所有FreeCAD建模、装配、姿态验证与图纸导出必须通过本机FreeCAD MCP。当前未找到规定的全局技能与统一启动器，工具列表未暴露FreeCAD能力，尚未执行CAD动作。此目录不包含伪造的FCStd、STEP、STL或已验证制造图纸。

已准备逐动作CAD作业清单：创建文档；单个方管/样件/夹座建模；重算；检查有效性/干涉；保存；独立检查保存文件；导出。所有带OCCT布尔的动作须使用`execute_code_async`，禁止将建模、重算、保存、导出和截图混成一次调用。恢复规定服务并读取完整调用纪律后，需按服务实际工具schema映射作业。

CAD恢复后还要检查：实体有效性，未预期穿透，脚垫与地面、夹座与样件接触；样件两肢/端边各观测方向的可见性；夹具工具可达性；紧固件空间；导出坐标与单位；零件BOM及实际采购规格一致。只有这些检查和实物验证完成，才可转制造放行。
