# 时间同步与原始射线数据协议 TS-01

2026-10-03设计规格。未在实物传感器运行。首版现成无人机由导入适配器执行能力审计，不能要求不存在的硬同步信号。

## 1. 必需时间记录

每条事件保存：`session_id`、`device_id`、`sequence_id`、原始时戳与时间尺度、转换后的`time_ns`、时戳定义、时钟锁定状态、估计不确定度`time_sigma_ns`、包计数/丢包信息、转换版本。UTC、GPS时间和开机计时不可混用；PPS只有秒边界，必须附对应整数秒标签。保留原始UTC/闰秒字段，不能用PC本地时间代替GNSS源。

`time_ns`内部使用任务相对连续时间，并记录UTC起点及UTC↔GPS转换。若UTC出现闰秒，不能让相对时间倒退。设备reset、PPS丢失、PTP源切换生成新时钟段与不确定度，不跨段强插值。

## 2. 相机曝光中点

硬触发边沿时间 `t_trigger` 与真正曝光开始时间不同。[Basler时序文档](https://docs.baslerweb.com/acquisition-timing-information)明确存在传感器起始延迟、输入传播/消抖、配置TriggerDelay及部分ROI延迟。

全局快门优先捕获实际ExposureActive上/下边沿，并对反馈传播延迟作台架标定：

`t_start = t_rise - d_rise`；`t_end = t_fall - d_fall`；`t_mid=(t_start+t_end)/2`。

曝光反馈定义见 [Line Source文档](https://docs.baslerweb.com/line-source)。该信号及延迟因型号/模式而异，不能未经核验就当绝对光学真值。用稳定发光时序靶或光电检测对可见曝光窗复核；每次记录曝光时间、ROI、触发模式、固件、时序配置和温度。

只有trigger和设定曝光而无实际反馈时，采用 `t_mid≈t_trigger+d_start+T_exposure/2`，`d_start`须标定，结果标 `estimated`。只有EXIF/文件时间时标 `coarse/unknown` 并禁用要求精确同步的测量解释。

滚动快门没有统一整幅曝光中点：保存行读出方向、`line_time`和参考行，使用 `t_mid(row)`；无法获取时以限制帧选择、增大时间误差和离线校正处理。全幅ExposureActive持续时间不能直接当每行曝光窗。

## 3. LiDAR采样时刻与扫描方向

保存每个实际射线事件的时刻、传感器坐标方向、回波数量/模式、量程、强度、状态与对应pose。首回波、最强回波、双/三回波模式要分开，不把同次发射的多个回波当多个独立射线。

[Livox官方协议](https://github.com/Livox-SDK/Livox-SDK/wiki/Livox-SDK-Communication-Protocol)示例说明包时戳为首点，点时间需按设备/格式间隔还原，并区分PTP、GPS、PPS与开机时戳。**不能把Mid-40示例的10 µs间隔套到Avia或其他设备**；确认实际采样/回波组织、固件和模式。网络到达时间、整帧时间、渲染点时间均不替代beam_time。

LiDAR点去运动用该点/发射时刻的INS插值。记录IMU、导航解的时间定义与延迟；外插必须限长且标识，GNSS异常不靠视觉模型强行掩盖。

## 4. 无回波能力等级与资格判定

| 等级 | 可得到的数据 | 允许机制 |
|---|---|---|
| C0 | 仅原图/滤波点云，无原始束时刻/轨迹 | 图像及几何匹配；禁用无回波损失 |
| C1 | 有效回波点、时间、位姿与可恢复方向 | 有效距离/可证自由空间；不能从缺失点推断未发射事件 |
| C2 | 有发射计数或invalid槽，但无可靠方向/拒收原因 | 用于数据质量与覆盖统计，禁用有方向无回波负证据 |
| C3 | 每次发射的时刻、方向、返回/未返回状态、设备健康、丢包及门限均可核验 | 符合下述条件的事件才可进入无回波负证据 |

无回波可用资格：确实发射且事件完整；方向可恢复；设备健康且时钟有效；射线在有效量程/FOV；不是丢包、过滤、雨雾抑制、低反射饱和/阈值或预处理删除的未知事件；前景遮挡和混合回波可解释；反射/回波概率经该设备和材料验证。保存 `eligible_no_return` 和 `exclusion_reason`。

**缺一个点、坐标全零、没有看到杆件、某束未收到包均不等于已知方向的无回波。** Avia非重复扫描可能需要逐事件扫描方向，不能用均匀扫描网格补出方向。只有厂商协议/SDK及实物样例证明这些字段，才提升到C3；本包未证明Avia提供完整C3资料。

负证据要以标定后的命中/检出模型加权，不能“一次未回波即缺杆”。无回波资格关闭时报告降级，仍可完成受限重建及补测建议。

## 5. 同步误差预算及测试

以 `e_sync≈(||v||+R||ω||)·|Δt|`给出一阶几何误差预算，另加安装形变、姿态和标定误差；并将旋转/杆方向影响作具体场景雅可比传播。先定允许几何误差，再反推同步需求。示例 `v=3 m/s`、`R=20 m`、`ω=0.1 rad/s` 时10 mm预算对应约2 ms；这只是分析算例，不是已达标参数。

台架同时记录PPS、触发、曝光反馈、串口时间、原始点包；人工制造PPS丢失、设备reset、网络丢包及磁盘阻塞，确认进入降级且不会伪造射线。设置移动平面/角钢靶验证时偏估计，保留未用于拟合的留出数据。实际采集频率和门槛由设备型号及测量目标确定。
