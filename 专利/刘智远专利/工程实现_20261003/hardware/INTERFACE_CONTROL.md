# 接口控制文件 ICD-01

状态：首版数据接口设计，2026-10-03。物理载荷接口是可选研发规格，未形成制造接线图或飞行安装许可。引脚、电平、线径和连接器型号须按最终设备/固件手册冻结。

## A. 首版地面接口

| 接口 | 输入/输出 | 必需信息 | 缺失处理 |
|---|---|---|---|
| I01 原图导入 | 原图、EXIF、相机元数据 | 文件哈希、frame_id、镜头/焦距、像素尺寸、曝光、时间定义；禁止只给压缩截图 | 不明确时间则标记估计并增大观测误差；缺相机资料则先标定 |
| I02 点云/原始包 | LAS/LAZ/PLY或原始包+轨迹 | 单位、坐标系、源设备/固件、回波类别、原始点时间定义和位姿 | 只有最终点云时，不启用未回波射线损失 |
| I03 结构初值 | 节点与杆件表 | 稳定唯一ID、端点连接、截面候选、来源 | 不把自动补全当真值；拓扑不稳定仍保留观测事实 |
| I04 测厚记录 | CSV及可选波形/照片 | member_id、测点、值/单位、探头、仪器与校准、不确定度、涂层处理 | 无对应杆件ID或校准失败不自动回灌 |
| I05 输出 | 参数模型、候选及证据表、建议补测任务 | 版本、单位、验算条件、未知项、失败原因、原始资料关联 | 阻止把未决规格导出成唯一已确认规格 |
| I06 飞行任务 | 离线建议视点/拍摄方向 | 目标杆件、预计区分力、候选适用条件 | 只输出建议，不直接连接或控制现成飞控 |

## B. 单位、坐标与刚体变换

内部几何长度以m、时间以整数ns、角度以rad、力以N、应力以Pa保存。公开CSV字段带单位后缀；不得混入无标注毫米值。源文件保持原值与原单位另存。

采用局部右手ENU坐标，Z向上。相机坐标约定X向右、Y向下、Z沿光轴向前；LiDAR与IMU坐标按各手册，经明示变换统一。`T_A_B`表示把B坐标点变为A坐标点，即 `p_A = R_A_B p_B + t_A_B`。四元数使用 `[w,x,y,z]`，必须写明主动/被动意义，禁止仅给四个数。GNSS杠杆臂以天线相位中心定义，结构节点以工程准线定义，两者不可混用。

每套标定记录 `calibration_id`、温度、安装编号、外参、协方差、参考时间与验证报告。拆装/调焦/改变扫描头角度后不沿用原外参。

## C. 可选载荷电气/数据接口

| 接口 | 功能 | 设计条件 |
|---|---|---|
| P01 | 保护后的直流母线 | 先确认飞行器可供电接口；台架使用受控电源。直接Avia与Converter范围不同 |
| P02 | 2路USB3图像 | 相机带锁线、独立带宽测试；记录丢帧和曝光元数据；USB到达时间不是曝光时间 |
| P03 | LiDAR Ethernet | 独立口或隔离VLAN，保留原始UDP包；记录包计数、固件、回波/坐标模式、同步状态 |
| P04 | GNSS/INS串口 | 实际RS232/422/OEM TTL需按订货版本选择，禁止接错电平；记录UTC/导航/状态及原始观测 |
| P05 | PPS和UTC标签 | 捕获PPS电平与串口UTC关联，保留闰秒/时间尺度说明及锁定状态 |
| P06 | 相机触发及曝光反馈 | 触发输出与ExposureActive输入分别记录；电平/极性/传播延迟台架校准 |
| P07 | LiDAR同步 | Avia协议示例使用RS485 PPS+UTC或PTPv2；不能直接把TTL线接入RS485接口 |
| P08 | 本地存储 | 原始包与解析结果分开；任务manifest与SHA-256；中断后可恢复 |

线束两端标签包含接口ID/源/目的/版本；对应原理图必须另外列实际pinout、电压、额定/峰值电流、屏蔽与应力释放。本文不会猜测设备针脚。

## D. 原始能力验收门槛

必须通过设备能力表和可重放样例包证明实际可用字段，而不能只依据宣传的“支持同步”。SDK声明可读点时间不代表可恢复全部发射射线。禁用项在manifest及报告中显式列出，详见 `SYNC_DATA_PROTOCOL.md`。
