# 系统需求与验收边界

版本：2026-10-03。产品基线：现成无人机＋地面工作站＋现场标定/测厚套件。本文定义设计要求和待验证目标，不表示对应软件功能已实现、专用设备已制造或完成野外飞测。软件完成状态以工程包中的可运行程序、测试记录和限制说明为准，不能由本需求文档反向认定。

## 1. 首版冻结与待确认事项

首版采用用户已有或可使用的无人机采集数据，在地面工作站执行分析。采集设备通过文件导出与标准化适配器接入，首版不控制飞控、不开发未知机型挂架、不承诺无人机接触测厚。专用同步双传感载荷、自动执行航线和机载推理列为后续选项。

待确认项：现有机型、相机、LiDAR 是否实际可用；原图和导航元数据导出权限；是否有原始束原点/方向/无回波日志；地面工作站 CPU/RAM/GPU；厚度仪器及校准条件；现场接近条件；预算。设备型号未知时不得以特定设备性能或接口作为已满足前提。

采集数据不足时首版仍应完成数据质检、候选登记、模型生成、未决原因与测量任务输出；不能降级后继续宣称完整厚度识别或自动承载合格判定。

## 2. 工程主线与数据对象

系统的唯一工程主线是：共享节点及有限厚度实体→物理观测与干扰→离散候选保留→指定工况验算分歧→噪声归一化动作分离度→遥测或局部测厚→同模型回灌→一致判定或明确未决。高斯面元、稀疏优化及因子图为可替换实现，不以引入模型品牌代替这一关系。

核心数据对象及强制字段：

| 对象 | 必需字段与单位 | 失败处理 |
|---|---|---|
| ProjectManifest | project_id、schema_version、坐标系、长度单位、时区、输入哈希、标定版本 | 单位或坐标不明则拒绝数值融合 |
| Node | node_id、xyz_m、固定/自由规范及来源 | 零长度/重复不一致节点报错 |
| Member | member_id、node_i、node_j、局部参考轴、存在候选、来源 | 未知节点或杆件身份歧义标未决 |
| SectionCandidate | candidate_id、member_id、b_m、t_m、phi_rad、eccentricity_m、规格来源、概率/权重口径 | 0<t<b不满足拒绝；候选不强制合一 |
| ImageObservation | image_id、相机内参/畸变、位姿、时间、曝光、质量掩膜、标定来源及不确定度 | 无有效位姿时仅登记、请求标定 |
| RayObservation | ray_id、origin_m、unit_direction、time_s、echo_state、range_m、有效范围、质量 | 无原始射线禁用无回波项 |
| Calibration | calibration_id、传感器、适用日期/配置、外参/时间偏移/误差、控制点或靶标证据 | 超出适用配置/日期触发复核 |
| EngineeringCase | 材料/边界/连接/荷载值或区间、单位、来源、适用验算规则、审核者 | 缺来源不签发确定性通过 |
| ThicknessObservation | member_id、leg、s、点位、thickness_mm、sigma_mm、仪器/校准、温度/涂层/耦合/重复性 | 无效读数隔离；单位转换留痕 |
| DecisionCandidate | 候选组合、工程输入版本、利用系数范围、PASS/FAIL/UNRESOLVED、求解质量 | 机构/失败不能静默删候选 |
| MeasurementTask | 目标候选对、模式、目标杆件/点位、姿态/方向/分辨率、D预测及误差、代价、限制 | 无效动作不得标为有效任务 |
| EvidenceRecord | run_id、输入/代码/配置哈希、剔除原因、测量回灌、停止原因 | 无证据输出不得进入正式报告 |

内部 SI 单位：米、秒、弧度、牛顿、帕、千克。厚度仪器的毫米读数在边界层显式转换，禁止仅依据数值大小猜单位。材料强度以 Pa，荷载以 N 或明确的力/长度单位，惯性矩以 m⁴。报告可以转换展示单位，但必须保留原单位和变换。

## 3. 功能需求

| ID | 必须行为 | 验收方法 |
|---|---|---|
| FR-01 | 导入清单、工程图、规格及观测；登记 RAW_RAYS / POINTS_ONLY / IMAGES_ONLY | 三种有效示例与错误单位示例均得到预期状态 |
| FR-02 | 生成有限厚度 L 实体内外面、厚度边面和端面；相邻杆件引用共享节点 | 面积/形心/惯性解析核对；共享节点变动同步影响相邻杆件 |
| FR-03 | 生成面元时固定几何参数映射，不能自由高斯变形代替规格 | 自动验证每个面元来源；几何变动由参数唯一重建 |
| FR-04 | 物理观测模型登记光学/激光噪声、足迹和标定；点云模式禁用无回波 | 构造低反射、遮挡、日志缺失用例，不误生成确定缺材 |
| FR-05 | 分离工程参数与干扰，尺度归一化、规范约束及门控 | 参数缩放不改变可辨识结论；位姿不确定度增大不会虚增信息 |
| FR-06 | 同宽异厚等价候选保留，记录绝对数据拟合支持/先验支持、截断风险及越库冲突 | 遮挡厚度边面样例保留8/10mm假设；全部候选不相容或贴库边界触发复核，不能相对最优即确认 |
| FR-07 | 工程条件必须有来源；未知材料/荷载/连接形成区间或未决 | 缺材料源的用例不输出确定PASS |
| FR-08 | 候选图、安装方向、偏心与截面属性进入验算接口 | 经独立可信求解器/人工算例核对，不只验证平均位移 |
| FR-09 | 真实缺材状态及机构保留；不为稳定补杆 | 删除关键杆件后报告机构或未决，候选图不自动恢复杆件 |
| FR-10 | 从判定分歧候选对选择测量，计算含不确定度的分离度 | 将噪声调大后分离度不增；不同观测单位归一化一致 |
| FR-11 | 遥测不能区分关键厚度时输出局部测厚任务 | 对所有可用动作D低于阈值的用例触发REMOTE_UNRESOLVABLE |
| FR-12 | 测厚校准/质量与多点腐蚀信息回灌同一模型 | 有效读数收缩候选；冲突触发扩展/核查；不以均值覆盖减薄 |
| FR-13 | 一致PASS、一致FAIL和UNRESOLVED分开；全部未决不能按一致通过停止 | 三种停止状态、机构/未知输入/预算不足均有明确原因 |
| FR-14 | 生成证据报告和可复现任务包 | 根据输入哈希、配置和代码版本复算，结果差异有解释 |

## 4. 承载接口边界

原型若只提供截面性质和线弹性响应，应显式声明 ELASTIC_SCREENING，仅用于算法流程演示。工业用途所声称的承载能力必须经过适用强度、稳定、连接与变形规则验证；不能把模态频率或顶点位移精度直接当成承载合格。

FE适配器输入候选实际图、完整截面惯性张量、朝向、偏心、材料、约束和荷载；输出逐项利用系数/范围、控制构件、适用规则、求解质量及模型限制。未知钢材等级不能根据颜色、纹理或测厚仪声速自动指定。材料或连接不确定度足以改变结论时，请求相应调查，厚度确定也不能结束全部工程复核。

## 5. 标定与现场测厚流程要求

几何标定靶属于首版地面套件：记录实际尺寸及测量证据、靶面/控制点编号、坐标基准和传感器配置。标定之后保留重投影/距离残差及不确定度，出现传感器安装变化时更新版本。靶标设计文件是工程设计，未制造前不能称作实物已检定。

现场测厚任务必须关联杆件ID和照片/坐标。先核对安全可达和仪器适用性，再按材料/厚度范围的已知试块校准；确认涂层、温度和耦合，记录重复读数，两肢及减薄疑点分别测量。超声过程不合格时不回灌有效因子；可改为合适的直接几何测量或输出未决。多点不均匀时保存厚度场或区间，不将健康点平均值作为最小厚度。

现成无人机任务应由现场人员依据适用作业规程核定。[DL/T 1482—2023 官方记录](https://std.samr.gov.cn/hb/search/stdHBDetailed?id=2E1288291A9F0971E06397BE0A0ABFD2)为作业文件核验入口，执行前复核现行状态及全文。本需求不固定未知设备的安全距离，也不把人员电气安全距离表直接当作无人机的全部安全模型。

## 6. 待验证的性能目标

以下均为研发验收目标，不是已测结果；验证平台、数据量与误差定义须共同记录。设备预算和数据导出能力未定，不能把这些数值承诺为现有无人机性能。

| 指标 | 初始目标 | 验证边界 |
|---|---|---|
| 有限截面面积/惯性数值一致性 | 与解析值相对差≤10⁻⁶ | 无圆角理想截面双精度单元测试，非实物误差 |
| 候选误确定率 | 在标注不可辨识对照集≤1% | 样本数、遮挡与真实规格明确；另报告置信区间，不能从少量样本推全场景 |
| 有效测厚回灌 | 所有有效/无效/冲突用例行为符合FR-12 | 合成流程与已知样件分开，目标不是任意仪器读数准确率 |
| 不确定区间校准 | 目标名义95%区间在独立可辨识测试集覆盖≥90% | 同时报告宽度；未辨识场景采用候选/区间，不强制窄区间 |
| 决策候选对选择 | 控制对照中有效模式优先于已证无效遥测模式 | 成功率/时间须实测，不承诺所有对象可完成 |
| 缺杆处理 | 关键缺杆机构用例100%保留状态、无自动补杆 | 功能验收，不等于现场缺杆检出率 |
| 数据导入与错误处理 | 定义用例100%可追溯，单位错误不静默通过 | schema与边界测试 |
| 小规模任务响应 | 32个局部候选、128个候选对的规划目标≤60s | 首次基准机冻结后验证；不包含全量图像/激光重建 |
| 工业节省工时 | 与等数据/等预算人工流程对比形成证据 | 目标有改善；本阶段不填未经试验的百分比 |

## 7. 非功能要求与交付界面

项目运行与安装仅使用项目 .venv；依赖锁定、输入哈希与版本保存。首版本地运行，不默认上传现场影像或设计资料。求解器超时、数值溢出、候选爆炸及失效标定均转为明确未决，不隐藏失败。存档不覆盖原始数据，新增测量形成版本。

首版交付包含软件原型与示例、数据schema/接口、标定与测厚SOP、现场套件设计资料、专利申请草稿、验证矩阵和证据模板。软件原型、套件工程设计、实际制造、标定检定、实塔飞测、可正式工程应用分别登记状态。未完成的阶段不得在报告中合并称为“产品已验证”。
