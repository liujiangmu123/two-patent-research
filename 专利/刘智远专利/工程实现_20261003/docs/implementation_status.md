# 实际实现状态与 FR-01–14 对照

冻结日期：2026-10-03。首版为**现成无人机＋地面工作站＋人工/外部算法关联观测＋现场标定与测厚流程设计**。专用同步载荷、无人机接触测厚、自动飞控、机载推理均非首版已实现功能。

## 2. 当前可复现证据

核心测试 23 项通过：面积/惯性、闭合面网格体积、相机与有限表面残差、LiDAR/影像肢宽朝向拟合、轴向 FE 力平衡与能量、遥测多解和测厚更新、真实缺杆机构、单位/材料/噪声校验、PLY 索引一致性，以及越库/矛盾/强先验/空观测/自由度/单候选来源/重复 ID/联合候选回归。

独立复核 A01–A08 已通过，记录在 `validation/AUDIT.md`；六杆案例初始 1833 个联合分歧对，一根测厚后仍有 408 对未决。覆盖约一半的单动作不能声称消除了全部系统歧义。这是合成算法回归，未执行真实塔试验。

`data/calibrated_geometry_case.json` 及结果展示人工关联、理想标定的合成几何拟合：初始宽 90 mm/朝向 0，生成参数宽 100 mm/朝向 0.18 rad；拟合 8 mm 候选约 98.988 mm/0.179192 rad，10 mm 候选约 100 mm/0.18 rad；likelihood-only 权重约 0.284/0.716，二者均保留。输入为无噪声特征均值与声明的非零不确定度，不能称为实测或真实标定相机精度。

默认遥测演示和追加合成测厚演示均可通过 CLI/API运行。10 mm 观测使候选权重趋近 1 是**给定模型下的相对权重**，不是 100% 真实安全保证；必须同时看绝对拟合、模型适用性和工程决定。

- 材料、连接和荷载现场调查；未知条件区间传播；完整梁/连接规范承载验算。
- 专用同步载荷制造、实物校准、飞测、机型适配挂架、自动航线和接触测厚执行。
- 在真实塔型和独立数据上的误确定率、置信覆盖、节省工时、工业安全/经济收益和专利授权结论。
