# 工业化路径与交付状态

版本：2026-10-03。首版路线：现成无人机＋地面工作站＋几何标定与局部测厚现场套件。本文为工程落地计划，阶段日期、性能和成本均须实际确认；不把软件示例运行等同于设备制造或实塔验证。

## 1. 工业用途与产品边界

优先用途为缺少可靠竣工图的旧角钢塔复核、改造前参数调查和灾后构件状态排查。产品先交付证据可追溯的候选、未决原因及测量任务，再与合资格结构评估流程集成。首版不独立签发塔体安全证明，不自动识别钢材强度等级，也不保证仅靠远程影像识别所有肢厚。

工业价值由具体工作流体现：对于会改变指定工况结论的同宽异厚规格，判断继续飞行能否区分；能区分则输出采集任务，不能区分则只对关键杆件安排适当测厚，测量后回灌至同一模型，减少把未测量参数当作确定输入的返工。

## 2. 交付内容和诚实状态分类

| 类别 | 本工程包对应内容 | 必须说明的状态 |
|---|---|---|
| 软件原型 | 输入模型、候选与分离度、任务/回灌/停止等程序和示例 | 能运行什么以实际测试记录为准；合成示例不算野外实测 |
| 软件工程设计 | 数据接口、噪声标定、观测反演、FE适配、异常与审计 | 已写需求不表示完整功能实现 |
| 专利文本 | 交底书、说明书、权利要求、摘要、流程附图及前案表 | 申请草稿；未宣称已提交、授权或无人申请 |
| 现场套件设计 | 可调几何标定靶、测厚辅助配套、编号与数据记录 | 工程设计；未制造/检定时明确标记 |
| 设备制造与校准 | 采购、加工、尺寸复测、仪器校准记录 | 需要独立实物证据，不能由CAD或SVG证明 |
| 实塔飞测 | 飞行记录、原始数据、现场测厚、复算及操作者记录 | 尚须安排和执行；没有记录不填已完成 |
| 工业应用 | 经审核的适用工况、验算规则与项目案例 | 以试点验收和适用范围确认，不从演示外推 |

专利目录中的 SVG 仅为算法与参数关系图，不是制造机械图。实际机械建模按项目 FreeCAD MCP 纪律由负责者执行，本文件不替代其模型与图纸。

## 3. 最小现场套件

优先复用现有无人机、相机/激光设备和地面工作站。首版新增套件可包括有编号的几何标定靶及尺寸记录、原图/导航/激光数据导出清单、现成合适测厚仪及匹配试块、杆件ID与两肢测点标识卡、校准/涂层/温度/耦合记录模板、现场复核报告模板。

不在预算与机型未知时设计飞行挂架，不采购尚无明确接口的专用载荷。若现有数据只有点云，先采用POINTS_ONLY模式；需要无回波或束足迹证据的高级功能在原始日志和传感器标定具备后启用。设备采购型号、价格、精度与接口必须在实际选型阶段核验。

## 4. 阶段和放行证据

| 阶段 | 工作与验证 | 放行证据 |
|---|---|---|
| P0 范围冻结 | 确認首版路线、数据权限、设备和工程输入；整理专利主核 | 需求版本、设备清单、数据样本清单和限制 |
| P1 软件闭环 | 有限实体、候选保留、分离度、任务切换、回灌、异常审计 | 可重复运行的合成用例；真实性标注；测试记录 |
| P2 已知样件 | 同宽8/10mm等对照样件、受控遮挡、真实测厚及传感标定 | 尺寸真值、原始数据、独立测试划分和误差定义 |
| P3 可信验算接口 | 已知材料/连接/荷载条件下与可信模型比较；检验朝向、偏心、缺杆机构 | 算例与参数来源；强度/稳定/连接/变形适用范围 |
| P4 实塔试点 | 获得真实现场数据和关键杆件测厚；等预算对比任务 | 飞行与现场记录、候选/误差/工时、未决率及人工审查 |
| P5 工程集成 | 数据存档、人员培训、规范化报告、运维接口与版本控制 | 试点验收、操作手册、支持范围与变更控制 |

试验结果反证原假设时，应修改模型或缩小用途。例如遥测对厚度始终无信息，应把产品定位为几何调查与目标测厚规划；连接和材料主导验算不确定度时增加相应调查，不将其归咎于“点云不够密”。

## 5. 基准对照和目标

至少比较：传统单一规格匹配；保留规格但按几何不确定度补测；本方法按承载分歧候选对选择模式。相同设备、工况、真值、采集预算和人工测量次数下比较误确定、未决、结论变化、总工时与测量成本。不能用一个方法更多飞行或更多测厚的数据证明其效率。

所有目标见 system_requirements.md；本阶段不填已达到精度、时延、测量节省率或授权概率。需要同时报告困难场景、失败和未决比例，不能只选成功图像。8/10mm为示意候选，不是项目实测结果。

## 6. 预算与资源决策

现成设备复用优先。预算应按软件研发、现成仪器/试块与校准、标定靶加工、样件真值、实塔采集与结构评估、专利代理与检索分项。尚未确认预算，本文不编造报价。

首版专用载荷预算为可选项而非必购项。只有证明现有导出数据无法支持关键功能、且升级能够带来可验证决策信息后，才进入专用载荷和机载软件设计。地面工作站升级同样依据真实基准的内存、时延与求解规模决定。

## 7. 专利与成果管理

已有前案非常接近，正式申请以有限实体参数生成、观测等价候选、承载分歧分离度、遥测无效测厚及同模型回灌为主线。提交前核对实现支持、分类号/引用链、同族与审查档案，并由代理人复核；检索中未发现完整相同组合不构成“未申请证明”。

存档区分发明构思时间、代码版本、实测数据取得时间与公开内容。外部发布前由负责者决定是否先提交申请；本文未自动发送材料、联系代理机构或公开项目数据。原始证据和失败记录保留，报告不能把待实现功能写成已经验证的效果。
