## 2. 独权特征的实现支持清单

| 特征 | 必须提供的实现/验证证据 | 证据欠缺时表述 |
|---|---|---|
| 共享节点、有限厚度L表面 | 参数schema、实体/面元生成、面积/惯性及端边检查 | 几何设计或原型，不称现场重建已完成 |
| 光学/激光物理观测 | 设备标定、预测残差、足迹/探测模型与数据模式 | 只提供接口时明确尚未完成反演 |
| 干扰消除与候选门控 | 规范、尺度、相关协方差、不可辨识对照样件 | 不宣称已校准95%后验 |
| 承载分歧 | 工程输入来源、可信验算插件、控制工况和模型限制 | 只做线弹性筛查时不称完整承载能力 |
| 噪声归一化分离度 | 预测观测/误差、连续和混合分布公式、有效/无效动作对照 | 模拟预测，不称测量已成功 |
| 遥测无效切测厚 | 可用动作集合、阈值依据、任务ID/点位/不确定度 | 流程演示，不称无人机自动接触测厚 |
| 同模型回灌与停止 | 有效、冲突、不可达、预算耗尽和缺杆机构用例 | 不确定状态保留，不签发安全证明 |

首版是否实现各项以程序与测试报告为准。申请时应删改不受实际实现或充分公开支持的表述；本次草稿并不要求把所有后续增强都纳入独权。
