# 真实杆件测厚与补测对照试验协议 FT-01

状态：2026-10-03 待执行方案。没有真实采集/测厚结果，不能据此报告准确率、节省比例、工业认证或现场安全结论。现有合成试验只验证数值机制。

## 1. 要证明的效果

证明“保留当前观测无法区分的角钢候选，并按承载结论分歧选择有效补测”可减少错误确定规格，且在相同补测成本下更快减少工程判断分歧。高斯显示质量作为辅助指标，不能替代规格/判断准确性。

预先登记试件/场地、设备能力、数据划分、荷载/材料来源、观察噪声、允许补测方式和成本。算法阈值只在开发集标定，最终测试集不得事后改阈值。对照方法是本工程独立实现的基线，不称为完整复现某篇论文或专利。

## 2. 分阶段样本

| 阶段 | 建议样本和覆盖，按预算调整并预登记 | 目的 |
|---|---|---|
| F0 台架 | 至少18件/布置：同肢宽不同厚度、不同朝向、遮挡、完整/缺件、镀锌/锈蚀参考件；受控距离与角度组合 | 确认观测相近的候选、几何模型、检出与测厚能力 |
| F1 可达结构 | 退役塔段或测试桁架，至少30根可完整获取尺寸证据的杆件；至少2种结构布置 | 避免只在理想独立角钢上成立；评估杆件ID和连接/遮挡 |
| F2 工业试点 | 由运行单位提供可达检验条件的存量塔，至少2个对象；关键规格需独立确认 | 评估资料缺失、真实任务成本和跨对象泛化 |

以上是建议样本量，不是统计功效保证。置信区间过宽时追加独立样本，不能用重复图像增加独立杆件数量。实际塔不得为实验拆除杆件或制造损伤；缺杆/弯曲测试只在受控试件或合成数据进行。

## 3. Ground truth与盲化

每根杆件固定 `object_id/member_id`、节点/面板关系和现场照片。独立检验人员记录两肢宽、厚度、朝向、位置、连接/偏心、孔/腐蚀情况及不确定度，量具与仪器有标定ID。材质与连接参数取证明资料/实检；没有资料时作为区间或未知，不能由照片猜为Q355。

厚度建议两肢各取3个沿轴向位置，每点重新耦合3次，记录全部读数和波形可用性；锈蚀不均时增加局部网格。若只有局部点，不能声明整杆最小剩余厚度已确认。内圆角/孔/螺栓附近另标不可测区。

退役件/校准件以卡尺/千分尺独立核验超声测厚；涂层与材料声速影响计入不确定度。`nominal_spec`、`measured_local_thickness`及验算采用的`effective_section`分别记录。没有可靠真值的杆件计为未验证，不能纳入准确率分母后填默认规格。

测试期间先封存真值，算法完成初始候选及补测建议后再释放被选择测点；最终评价人员读取完整真值。训练/开发/测试按结构对象或布置划分，同一杆件不同帧不跨集合泄漏。

## 4. 同成本对照

- B0：常规点云/多视几何识别后匹配唯一最近规格；输出其置信或失败状态。
- B1：参数绑定表面重建＋保留候选，按均匀/固定视角补拍，不用承载分歧选择。
- B2：按几何不确定性/信息增益补测，但不使用验算分歧或传感器模式可分辨门槛。
- P：完整主案：有限厚度参数绑定、多模态误差模型、不可辨候选集合、承载结论分歧、有效观测门槛与测量模式切换。

各方法共用同一初始原始资料、材料/荷载条件、结构初值与最大成本。成本登记飞行/采集时间、人工可达时间、测厚点数、处理资源；一张照片和一次现场测厚不能假设等价成本。补测建议由实际采集人员执行，记录无法执行的任务和原因。

增加消融：去掉厚度生成、强制唯一规格、忽略时间/束足迹、关闭模式切换、只看RGB图像质量。所有补全/推断点均带来源标记，不能再作为独立LiDAR观测参加同轮优化。

## 5. 统一评价

| 指标 | 记录方式 |
|---|---|
| 几何与规格 | 节点/肢宽/朝向误差；真实规格是否在候选集；候选大小；厚度有辨识证据的比例 |
| 不确定度 | 预设95%区间/集合覆盖、区间宽度、校准曲线及独立杆件统计置信区间 |
| 拓扑 | 真缺件识别、误删完整杆件、未知区域保留；FE奇异只作报警，不自动补杆 |
| 判断 | 在已确认材料/连接/荷载下，错误合格与错误不合格、未决比例、分歧消除率 |
| 补测 | 同预算终点的错误判断与未决比例、达到预登记目标所需时间/点数，无法执行率 |
| 工程运行 | 原始资料导入失败、时间异常、丢帧/丢包、峰值内存/显存、处理时长及人工修正量 |

承载判断真值来自独立工程模型/检验依据；不把算法自身同一个有限元输出当独立真实承载能力。模型范围、构件屈曲、连接、腐蚀与荷载未覆盖时只评价对应受限问题。

## 6. 暂定验收目标与停止条件

在采集前由项目和工程评价人员冻结指标及预算。建议初期目标：已知完整件不因FE稳定化被删除/新增；C0–C2资料从不启用未回波负证据；关键测试不产生未标注的错误合格；真值候选覆盖率及误差目标有统计区间；P在同成本对照下体现减少误判/未决的证据。小样本零误判不能宣传总体误判率为零。

达不到辨厚条件时验收正确输出未决及有效测厚任务的能力，不用强制规格匹配把任务改为“成功”。数据能力不足、测厚校准失效或真实资料无法完整对照时停止相应效果结论，保留原因并补充样本。工业扩展需要新的截面/连接/材料验证，不能把塔上结果直接推广到全部钢结构。
