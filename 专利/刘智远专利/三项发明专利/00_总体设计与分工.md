## 2. 规避与申请策略
- 必须逐条比对的现有技术：PTM 论文；CN120976438A（南京邮电大学，激光点映射高斯椭球 + 分层聚类）；CN120976449B（跨源高斯泼溅）；GaussianPlant、CurveGaussian、SketchSplat；CN117933030B（点云测截面查角钢库）；CN121053109A（点云拓扑图反推缺材）；CN121432427A（武汉大学，铁塔 PS 像元仿真）；EGU26-11441；输电巡检航线/安全距离专利；视频测振（相位法、DIC）与无靶标视觉测振专利。
- 用户自有在先申请 `专利/InSAR-GNSS联合监测装置`（地面立杆 + GNSS + 角反射器 + 空间偏置量）：C 的角反射器为“夹持于塔材、无立杆、无 GNSS、无落地支撑”的不同结构，不得落入其权利要求。
- 五件同日提交，避免同一申请人在先申请构成抵触申请；各件说明书只以“可采用任意方法获得”引用其他件的产出，不披露其他件的核心细节。

## 4. 工具链
- 申请文件生成：`00_共享/工具/专利生成器/build_patent_docx.js --root <专利文件夹> --dpi 300`（Node + docx，`$env:NODE_PATH=(npm root -g)`）；校验：`check_patent.py --root <专利文件夹>`；报告类 md→docx：`md2docx.py`；docx→pdf：`docx2pdf.ps1`（Word COM）。
- 仿真：共享库 `00_共享/towerkit`（参数化格构塔、空间梁有限元、角钢截面库、激光扫描仿真、SAR 几何、风荷载）。
- Python 一律 `.venv\Scripts\python.exe`；新增依赖写入根目录 `requirements.txt`。
- FreeCAD：已有硬件模型为 freecadcmd 脚本生成（`05_硬件设计/脚本/`）。今后修改须经 FreeCAD MCP 串行执行；不得操作他人正在使用的 FreeCAD 窗口。
