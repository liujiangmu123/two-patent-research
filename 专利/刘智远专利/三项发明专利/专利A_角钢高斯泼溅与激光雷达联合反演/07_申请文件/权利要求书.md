# 权利要求书

1. 一种基于桁架图参数化角钢高斯泼溅与激光雷达联合反演的输电塔杆件级数字孪生重建方法，其特征在于，包括以下步骤：

S1，获取由无人机搭载的同步采集载荷对待重建输电塔采集的多视影像、激光测距记录及各自的采集时刻与位姿，所述激光测距记录包括有回波的激光射线及未产生回波的激光射线；

S2，获取所述输电塔的初始桁架图，所述初始桁架图包括节点集合与连接节点的杆件集合；

S3，以所述节点的坐标、每根杆件的角钢截面参数及每根杆件的存在概率为待优化的桁架参数，所述角钢截面参数至少包括肢宽、肢朝向角与准线偏心；通过确定性生成函数将每根杆件展开为分别位于角钢两肢平面内、相互正交的两组面元高斯条带，相连杆件共享同一节点，面元高斯的中心、尺度、朝向与不透明度均由所述桁架参数确定且不作为独立优化变量；

S4，对由所述面元高斯构成的同一高斯场，按各影像的相机位姿渲染颜色与塔体轮廓，并沿各激光射线渲染期望距离与命中概率；

S5，构建联合目标函数，所述联合目标函数至少包括影像光度项、塔体轮廓项、有回波射线的激光距离项、由未产生回波的激光射线构成的无回波负证据项以及桁架图先验项；经所述确定性生成函数的雅可比将所述联合目标函数的梯度回传至所述桁架参数并迭代优化；

S6，根据所述存在概率剪除或保留杆件，更新所述桁架图的拓扑；

S7，将优化后的截面参数离散吸附到角钢规格表中的规格；

S8，在优化收敛点对所述联合目标函数作拉普拉斯近似，得到节点协方差及截面参数标准差，并据此计算每根杆件的置信度；

S9，输出梁单元有限元模型，所述梁单元有限元模型中每根杆件的单元带有所吸附的角钢规格、由所述准线偏心确定的偏心连接以及所述置信度属性。

2. 根据权利要求1所述的方法，其特征在于，所述确定性生成函数为：沿杆件轴向将杆件均分为K段，每肢沿肢宽方向分为P列，第(k,m,p)个面元高斯的中心为 μ = v_i + ((k−½)/K)(v_j − v_i) + δ + ((p−½)/P)·b·n_m，其中v_i、v_j为杆件两端节点坐标，δ为准线偏心向量，b为肢宽，n_m为第m肢的肢向单位向量，n₁由参考向量在垂直于杆件轴向的平面内的投影绕杆件轴向旋转肢朝向角得到，n₂为杆件轴向与n₁的叉积；面元高斯的切向轴为杆件轴向与n_m，切向尺度分别与L/(2K)及b/(2P)成正比，L为杆长；面元高斯的不透明度为存在概率与基准不透明度之积。

3. 根据权利要求1所述的方法，其特征在于，所述沿各激光射线渲染期望距离与命中概率包括：将激光束建模为各向异性高斯光束，其足迹协方差随沿光束距离按发散角线性放大并随扫描相位旋转；将所述足迹协方差叠加到各面元高斯在射线横截面内的投影协方差上，闭式计算各面元高斯的命中能量占比；按沿光束深度排序累积得到所述命中概率与期望首回波距离。

4. 根据权利要求3所述的方法，其特征在于，所述命中能量占比为 h = α·|Σ⊥|^{1/2}/|Σ⊥ + Σ_beam|^{1/2}·exp(−½ρᵀ(Σ⊥ + Σ_beam)⁻¹ρ)，其中α为面元高斯不透明度，Σ⊥为其横向投影协方差，Σ_beam为足迹协方差，ρ为面元高斯中心相对激光射线的横向偏移。

5. 根据权利要求1所述的方法，其特征在于，所述无回波负证据项为对穿过塔体包围区域且未产生回波的激光射线累加 −log(1 − H)，并对实测距离大于某面元高斯深度的激光射线累加深度小于实测距离减容差部分的 −log(1 − H)，H为相应的命中概率。

6. 根据权利要求1所述的方法，其特征在于，所述桁架图先验项包括鲁棒对称项，所述鲁棒对称项以 Geman–McClure 核度量节点与其经塔身对称变换后的对应节点之间的距离；所述方法还包括输出逐节点的对称破缺量，并将对称破缺量超过阈值且置信度高于阈值的节点标记为高低腿、弯曲、错装或损伤候选。

7. 根据权利要求1所述的方法，其特征在于，步骤S3中，主材节点的坐标为自由变量，斜材与辅材的端点表示为所依附主材段两端节点的线性插值，插值系数作为所述桁架参数之一。

8. 根据权利要求1所述的方法，其特征在于，步骤S5的迭代优化按以下阶段进行：第一阶段固定拓扑并冻结肢宽与肢厚，优化节点坐标、肢朝向角、准线偏心与外观参数；第二阶段解冻肢宽与肢厚并加入规格软吸附项；第三阶段周期性执行步骤S6；第四阶段完成步骤S7后固定规格并微调节点坐标、肢朝向角与准线偏心。

9. 根据权利要求1所述的方法，其特征在于，步骤S6包括：剪除存在概率低于第一阈值的杆件；在由主材与边界杆件围成的面板内按面板语法生成候选杆件，所述面板语法至少包括单斜、交叉、K型与再分式中的一种，当候选杆件沿线的轮廓残差或激光距离残差高于第二阈值时激活该候选杆件参与优化；每次拓扑变更后组装结构总刚度矩阵并检测零能模态，当出现零能模态时撤销该次剪除或保留使零能模态消失的候选杆件。

10. 根据权利要求9所述的方法，其特征在于，对于闭环塔头，先由多视轮廓与激光测距记录拟合塔头外边界闭环作为边界杆件，再在所述边界杆件围成的面板内生成候选杆件。

11. 根据权利要求1所述的方法，其特征在于，步骤S7中，所述角钢规格表为热轧等边角钢规格表，先以对规格表各规格的软最小值距离作为规格软吸附项并退火，再对每根杆件取加权距离最小的规格，并在由对称变换关联的杆件组及同一面板分组内对规格进行多数一致化。

12. 根据权利要求1所述的方法，其特征在于，步骤S8中，以残差加权雅可比构造 Gauss–Newton 海森近似并叠加先验海森，求逆得到桁架参数协方差；杆件置信度为存在概率、以肢宽标准差与肢宽之比为自变量的递减函数、以肢朝向角标准差为自变量的递减函数及两端节点置信度最小值的乘积；并输出每根杆件各规格的后验概率。

13. 根据权利要求1所述的方法，其特征在于，还包括补测步骤：计算有限元关注量对所述桁架参数的灵敏度矩阵，以所述灵敏度矩阵和杆件置信度构造力学风险加权矩阵A；对候选视点由当前模型预测其观测信息矩阵H_ξ，以 tr(AΣ) − tr(A(Σ⁻¹ + H_ξ)⁻¹) 减去飞行代价作为视点效用，Σ为桁架参数协方差，序贯贪心选择补测视点并更新Σ；对补测数据重复步骤S3至S9。

14. 根据权利要求13所述的方法，其特征在于，由激光测距记录识别导线、跳线、绝缘子串与带电金具组成带电体集合，按线路电压等级确定最小安全距离，并叠加定位误差裕量与无人机外廓半径，得到带电安全壳；所述补测视点及相邻视点间航段的离散采样点均位于所述带电安全壳之外且与塔体的距离不小于防碰撞距离；不满足时以调整相机俯仰、激光倾角或改用仰视相机代替靠近。

15. 根据权利要求1所述的方法，其特征在于，所述桁架参数还包括相机与激光雷达之间的外参及时间偏移，在步骤S5中以杆件在影像轮廓与激光距离中的几何对应为靶标对所述外参及时间偏移进行联合在线标定；所述相机的采集时刻为由曝光有效信号上升沿与下降沿确定的曝光中点时刻。

16. 根据权利要求1所述的方法，其特征在于，当影像缺失或不可用时，去除所述影像光度项与塔体轮廓项，仅以激光距离项、无回波负证据项与桁架图先验项优化所述桁架参数，所述激光距离项按权利要求3的足迹协方差计算。

17. 根据权利要求1所述的方法，其特征在于，在多期复测时，以前期输出的桁架图、角钢规格作为本期的初始桁架图与截面初值，仅优化节点坐标与存在概率，输出逐杆件的位置变化量、存在状态变化与置信度。

18. 一种输电塔杆件级数字孪生重建系统，其特征在于，包括：
数据获取模块，用于获取多视影像、含未产生回波射线的激光测距记录、采集时刻与位姿及初始桁架图；
参数化生成模块，用于以节点坐标、杆件角钢截面参数与存在概率为桁架参数，经确定性生成函数将每根杆件展开为角钢两肢相互正交的两组面元高斯条带；
双模态渲染模块，用于对同一高斯场渲染影像颜色与塔体轮廓，并沿激光射线渲染期望距离与命中概率；
联合优化模块，用于构建包括影像光度项、塔体轮廓项、激光距离项、无回波负证据项与桁架图先验项的联合目标函数，并将梯度经所述生成函数回传至桁架参数；
拓扑与规格模块，用于按存在概率更新拓扑并将截面参数离散吸附到角钢规格表；
置信度模块，用于以拉普拉斯近似计算节点协方差与杆件置信度；
有限元导出模块，用于输出带角钢规格、偏心连接与置信度属性的梁单元有限元模型；
以及补测规划模块，用于以杆件置信度与有限元灵敏度加权的信息增益在带电安全壳外选择补测视点。

19. 一种用于权利要求1至17任一项所述方法的同步采集载荷，其特征在于，包括：
减振挂架（1），上端设有与无人机连接的快拆接口（11）；
刚性主框架（2），经减振器（12）悬挂于所述减振挂架（1）；
激光扫描头（3），经倾角调节机构（4）安装于所述主框架（2），所述倾角调节机构（4）包括支撑所述激光扫描头（3）的耳轴（41）、驱动所述耳轴（41）的电机（42）与自锁减速副（43）以及直接测量所述耳轴（41）转角的绝对式编码器（44）；
俯视测绘相机（5），固定于所述主框架（2）下部，为全局快门或机械快门相机；
仰视相机（6），固定于所述主框架（2），光轴斜向上，用于观测塔头内侧与横担下表面；
GNSS/INS 组合导航单元（7），固连于所述主框架（2）；
同步板（8），接收所述组合导航单元（7）的秒脉冲与时间报文，向所述俯视测绘相机（5）与仰视相机（6）输出硬触发脉冲，接收两相机的曝光有效信号并以其上升沿与下降沿的中点作为曝光中点时刻打时间戳，向所述激光扫描头（3）提供时间同步，并对所述编码器（44）读数打时间戳；
以及机载计算单元（9），与所述同步板（8）、激光扫描头（3）及两相机通信，用于执行所述补测视点的计算并向飞控输出补测航点。

20. 根据权利要求19所述的同步采集载荷，其特征在于，所述自锁减速副（43）为蜗轮蜗杆副；所述倾角调节机构（4）设有限定倾角范围的机械限位块（45）；所述激光扫描头（3）为两个，分别以相反倾角布置，使两者扫描平面交叉。

21. 一种计算机可读存储介质，其上存储有计算机程序，其特征在于，所述计算机程序被处理器执行时实现权利要求1至17任一项所述方法的步骤。
