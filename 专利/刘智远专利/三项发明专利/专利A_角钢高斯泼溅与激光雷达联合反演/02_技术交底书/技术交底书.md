# 技术交底书

发明名称：一种基于桁架图参数化角钢高斯泼溅与激光雷达联合反演的输电塔杆件级数字孪生重建方法、系统及同步采集载荷

申请类型：发明专利（方法＋系统＋装置＋存储介质）
技术领域：电力输电线路数字化运维；无人机激光雷达测量；可微渲染三维重建；钢结构有限元建模。
版本：V1.0（2026-10-01）。仿真数字以 `04_仿真验证/数据/关键结果摘要.json` 为准，未出结果处以【待填:指标名】占位。

## 1 背景技术

### 1.1 行业需求

格构式角钢输电塔是架空线路的承力骨架。存量老旧塔大量缺少竣工图，遇极端风、覆冰、基础沉降时，运维单位需要可直接进行有限元校核的杆件级（LoD3）模型：每根杆件的两端节点、所属类别（主材、斜材、辅材）、角钢规格（肢宽 b × 肢厚 t）、肢朝向与偏心连接。

### 1.2 现有技术及其不足

1. 纯激光点云杆件级重建。Chang 等提出的 PTM 方法（IEEE TII，2026）由无人机激光扫描（ULS）点云重建桁架模型：对称增密与双边锐化、90° 旋转 ICP 分解、3D→2D→1D 的"节点优先"峰值检测、固定拓扑图优化，再赋梁单元做风载静力分析。其公开数据：平均点密度 152.6 pts/m²，节点 RMSE 0.098 m，点到模型 RMSE 0.137 m，主/斜/辅材归一化图编辑距离 0.048/0.035/0.107；O 型塔头被排除；截面按主/斜/辅三档统一赋值。论文自述局限包括：点稀使 40–250 mm 肢宽横向只有 1–2 个点；对称增密会抹平高低腿、非对称和损伤；分解假设不适用闭环塔头；尚未给出杆件置信度；塔脚植被遮挡需更密环绕飞行。
2. 点云截面测量查库。CN117933030B 用分割模型由点云得到截面参数，再从截面库匹配肢宽肢厚并建立有限元模型；精度受点密度限制，肢朝向、偏心无从约束，结果无不确定度。
3. 点云拓扑图检测。CN121053109A 由点云聚类、交汇点密度峰值得到节点—边拓扑图，规则校验后反推缺失塔材；拓扑图是描述工具，不参与观测反演。
4. 激光雷达＋高斯泼溅的电力塔重建。CN120976438A 把配准后的每个激光点映射为一个高斯椭球，沿 Z 轴分层聚类，重建几何与真实表面；高斯为无语义的点表达，无法输出杆件、截面与有限元模型。CN120976449B 公开跨源数据的改进高斯泼溅三维重建，属通用方法。
5. 视觉领域的结构化/参数化高斯。GaussianPlant 以圆柱为枝干结构基元、外观高斯绑定其上；CurveGaussian、SketchSplat 把参数曲线/草图边采样为高斯并把梯度回传到曲线参数，带视觉准则的合并、分裂、剪枝。三者都只用影像，不共享节点、不含截面规格、不输出有限元；圆柱投影宽度与视向无关，角钢肢朝向不可观测。
6. 激光雷达可微渲染。SplatAD 等在同一高斯场渲染相机图像与激光距离、强度、射线丢失，面向自动驾驶重仿真；高斯为自由高斯，激光按点状射线处理。无人机激光足迹（如 0.4 mrad 发散角在 30 m 处约 12 mm 并随距离增大；非重复扫描雷达沿长轴可达 0.1 m 以上）与辅材肢宽同量级，现有方法未建模足迹与细杆耦合。
7. 补测视点规划。FisherRF、质量引导 NBV、FC-Planner 等在几何/外观参数空间计算信息增益或覆盖度；未与结构参数不确定度、有限元灵敏度以及带电安全距离结合。
8. 采集硬件。DJI Zenmuse L2、LiAir X3 等一体化载荷集成激光雷达、测绘相机与 IMU，激光头固定朝向，无仰视相机，塔头内侧与横担下表面观测不足；外参与时间同步依赖出厂标定。

## 2 要解决的技术问题

1. 在激光点稀与竖向遮挡条件下，提高桁架节点定位精度。
2. 反演每根杆件的角钢规格、肢朝向和准线偏心，而不是统一赋值。
3. 识别多余或缺失杆件，适用闭环塔头，且拓扑保持几何不变。
4. 对每个节点与杆件给出定量置信度，并据此安全地规划补测。
5. 提供能满足上述联合反演所需时空对齐精度、且能覆盖塔头内侧的采集载荷。

## 3 技术方案概述

以初始桁架图为参数，把每根杆件经确定性生成函数展开为角钢两肢的面元高斯条带；同一高斯场既渲染影像颜色与轮廓，又沿每条激光射线渲染期望距离和命中概率（含足迹协方差）；以光度、轮廓、激光距离、无回波负证据与图先验构成联合损失，梯度只回传到节点、截面与存在概率；按存在概率和零能模态检查更新拓扑；截面离散吸附到 GB/T 706 热轧等边角钢规格表；拉普拉斯近似给出节点协方差与杆件置信度；输出含规格、偏心、置信度的梁单元有限元模型；以"置信度 × 有限元灵敏度"的信息增益在带电安全壳外选补测视点。硬件为双倾角激光—双相机同步采集载荷。

## 4 技术方案详述

### 4.1 总体流程（对应图1）

S1 同步采集：载荷按绕塔螺旋航线采集多视影像、激光逐点记录（发射时刻、方向、回波序号、距离、强度，含无回波射线）与 GNSS/INS 位姿，PPS 硬触发并回传曝光中点时刻。
S2 初始化：由激光点云得到初始桁架图 G₀=(V,E)（可用 PTM 类节点优先方法、主材 RANSAC＋节点峰值或已有设计模板）；截面按主/斜/辅三档取初值；塔体分割得影像掩膜 M；非塔体点初始化背景自由高斯。
S3 参数化与生成：建立桁架参数 Θ，经生成函数 Γ(Θ) 得到结构化面元高斯集合。
S4 双模态可微渲染：影像颜色/累计不透明度渲染；激光期望距离与命中概率渲染（含足迹协方差）。
S5 联合优化：分阶段最小化联合损失，梯度经 ∂Γ/∂Θ 回传。
S6 拓扑更新：存在概率剪除、面板语法候选新增、零能模态检查。
S7 规格吸附：连续截面 → 离散角钢规格。
S8 置信度：拉普拉斯近似得 Σ_Θ，计算杆件置信度。
S9 有限元导出：梁单元模型（规格、偏心、置信度属性）。
S10 补测：置信度 × 灵敏度加权信息增益，在安全壳外选视点并回到 S1 增量采集；满足阈值则输出数字孪生模型。

### 4.2 桁架参数化

节点集 V={v_i∈R³}。主材节点 v_i 为自由变量；斜材、辅材端点依附于主材段 (M_j, M_k)：

  v = M_j + s·(M_k − M_j)，s∈[0,1]　　　(1)

杆件 e=(i,j)∈E 的参数：肢宽 b_e、肢厚 t_e、肢朝向角 φ_e、准线偏心 δ_e=(δ_e¹,δ_e²)（在截面平面内）、存在 logit ℓ_e，存在概率 π_e=σ(ℓ_e)=1/(1+e^{−ℓ_e})。

全部待优化参数 Θ = {v_i（主材）, s（依附端点）, b_e, t_e, φ_e, δ_e, ℓ_e} ∪ {外观参数} ∪ {外参 T_LC, 时间偏移 Δt（可选）}。

局部坐标：杆长 L_e=‖v_j−v_i‖，轴向 a_e=(v_j−v_i)/L_e。取参考向量 r（主材取指向塔身中心轴的水平向量，横担杆件取竖直向量），

  u_e = normalize(r − (r·a_e)a_e)，n₁ = R(a_e, φ_e)·u_e，n₂ = a_e × n₁　　　(2)

其中 R(a, φ) 为绕 a 转 φ 的 Rodrigues 旋转。角钢两肢分别张成 (a_e, n₁) 与 (a_e, n₂) 平面，背棱（两肢交线）位于 c_e(ξ) = v_i + ξ(v_j−v_i) + δ_e¹n₁' + δ_e²n₂'，n₁'、n₂' 为 u_e 及 a_e×u_e。

### 4.3 高斯生成函数（对应图3）

沿轴分 K_e = ⌈L_e/Δ⌉ 段（Δ = κ_Δ·b_e，κ_Δ 取 0.5～1.0），每肢沿肢宽分 P 列（P 取 2）。第 (k, m, p) 个面元（k=1..K_e，m∈{1,2} 为肢号，p=1..P）：

  中心 μ_{e,k,m,p} = v_i + ((k−½)/K_e)(v_j − v_i) + δ_e + ((p−½)/P)·b_e·n_m　　　(3)
  切向轴 (t_u, t_v) = (a_e, n_m)，法向 n = a_e × n_m
  尺度 (σ_u, σ_v, σ_n) = (c·L_e/(2K_e), c·b_e/(2P), ε_t)，c≈1.1 保证无缝，ε_t = t_e/2 或取极小值（二维面元）
  协方差 Σ_g = R_g diag(σ_u², σ_v², σ_n²) R_gᵀ，R_g = [a_e, n_m, a_e×n_m]
  不透明度 α_g = π_e·α₀（α₀ 取 0.95～0.99）　　　(4)

外观：每个面元保留独立颜色 c_g（或低阶球谐 SH_g），只影响颜色，不影响几何。节点板与螺栓群以"节点附属小面元"表示，强 L2 正则约束其尺度与位置。背景（导线、绝缘子、植被、地面）用自由高斯，且不得占据塔体掩膜像素。

记 Γ: Θ → {(μ_g, Σ_g, α_g)}。高斯几何不作为独立变量；梯度链式回传：

  ∂L/∂v_i = Σ_{e∋i} Σ_{g∈Γ(e)} [ (∂L/∂μ_g)(∂μ_g/∂v_i) + (∂L/∂Σ_g):(∂Σ_g/∂v_i) ]　　　(5)

同理得 ∂L/∂b_e、∂L/∂φ_e、∂L/∂δ_e、∂L/∂ℓ_e。被遮挡的节点也能从其连接的全部杆件沿线证据中获得约束。

截面可辨识性：设 w 为像平面内垂直于杆件投影的单位方向，L 形截面投影宽度

  W(w) = b_e·[ max(0, n₁·w, n₂·w) − min(0, n₁·w, n₂·w) ]　　　(6)

随视向在约 0.71b～1.41b 之间变化（圆柱恒为直径），故 ≥3 个视向即可同时确定 b_e、φ_e；偏心 δ_e 由轮廓中线相对节点连线的偏移确定。

### 4.4 影像投影与渲染

相机 c 的位姿 (R_c, t_c) 由 GNSS/INS 位姿、外参 T_LC 与曝光中点时刻 τ_c 插值得到。高斯中心投影 x_g = π_K(R_c μ_g + t_c)；二维协方差按 EWA 局部仿射近似：

  Σ'_g = J_g W_c Σ_g W_cᵀ J_gᵀ + s₀² I　　　(7)

W_c=R_c，J_g 为透视投影在相机坐标 y_g=R_cμ_g+t_c 处的雅可比，s₀ 为抗混叠低通（取 0.3 像素）。二维面元也可采用射线—面元求交的精确形式（2DGS），效果等同。

像素 r 处，按深度排序的高斯响应 G_g(r)=exp(−½(r−x_g)ᵀΣ'_g⁻¹(r−x_g))，

  颜色 C(r) = Σ_k c_k α_k G_k(r) T_k，T_k = Π_{l<k}(1 − α_l G_l(r))　　　(8)
  累计不透明度 O(r) = Σ_k α_k G_k(r) T_k；仅统计结构高斯得塔体轮廓 O_s(r)　　　(9)

### 4.5 激光雷达渲染（含足迹协方差）

每条激光射线 ℓ：发射时刻 τ_ℓ、起点 o_ℓ、方向 d_ℓ（由 τ_ℓ 时刻位姿插值，消除运动畸变）。在以 d_ℓ 为光轴的局部射线坐标中，高斯 g 的沿光束深度 z_g = d_ℓ·(μ_g − o_ℓ)，横向偏移 ρ_g ∈ R²（μ_g−o_ℓ 在垂直 d_ℓ 平面的投影），横向协方差 Σ⊥_g（Σ_g 在该平面的投影，单位 m²）。

激光束建模为各向异性高斯光束，足迹协方差随距离与扫描相位变化：

  Σ_beam(z, ψ) = R(ψ) diag( (w₀₁ + z·θ₁/2)², (w₀₂ + z·θ₂/2)² ) R(ψ)ᵀ / 4　　　(10)

θ₁、θ₂ 为两主方向全发散角（1/e² 定义），w₀ 为出射光斑半径，ψ 为足迹长轴在射线横截面内的方位（机械旋转式取扫描方向，非重复扫描式按扫描相位查表）。因高斯与高斯卷积仍为高斯，光束—高斯耦合后的命中能量占比闭式为：

  h_g = α_g · |Σ⊥_g|^{1/2} / |Σ⊥_g + Σ_beam|^{1/2} · exp( −½ ρ_gᵀ (Σ⊥_g + Σ_beam)⁻¹ ρ_g )　　　(11)

（|Σ⊥_g + Σ_beam| 中 Σ⊥_g 不含尺度归一，当 Σ_beam→0 时退化为点状射线的 α_g G_g。）按 z_g 排序后：

  命中概率 H_ℓ = Σ_k h_k Π_{l<k}(1 − h_l)　　　(12)
  期望首回波距离 D_ℓ = Σ_k z_k h_k Π_{l<k}(1 − h_l) / (H_ℓ + ε)　　　(13)
  期望强度 I_ℓ = Σ_k ρ_k^int h_k Π_{l<k}(1 − h_l)（可选，ρ^int 为每个高斯的反射率参数）

多回波设备时，按 z 聚类将第 n 回波与第 n 个能量峰对应。

### 4.6 无回波负证据

对穿过塔体包围盒（或沿射线经过任一结构高斯 3σ 区域）且未产生回波的射线集合 𝓛₀，以及有回波但测距 d_ℓ 明显大于某结构高斯深度（"穿透"）的射线，构造负证据：

  L_drop = − Σ_{ℓ∈𝓛₀} log(1 − H_ℓ + ε) − Σ_{ℓ∈𝓛_pass} log(1 − H_ℓ^{(z<d_ℓ−τ_d)} + ε)　　　(14)

其中 H_ℓ^{(z<d−τ_d)} 只累计深度小于实测距离减容差 τ_d 的高斯。负证据压低"不存在"杆件的 π_e，并约束肢宽不能大于真实值；配合天空背景下的影像轮廓，对细辅材的存在判定最敏感。

### 4.7 联合损失

  L = L_photo + w_m L_mask + w_r L_range + w_d L_drop + w_sym L_sym + w_pl L_plane + w_c L_spec + w_π L_sparse + w_reg L_reg　　　(15)

- 光度：L_photo = (1−λ)‖C − Ĉ‖₁ + λ(1 − SSIM(C, Ĉ))，λ=0.2。
- 轮廓：L_mask = BCE(O_s, M)，对掩膜边界 3 像素带加权 2 倍。
- 激光距离：L_range = Σ_{ℓ有回波} H_ℓ·ρ_Huber(D_ℓ − d_ℓ; δ_H) / σ_d² ＋ Σ −log(H_ℓ + ε)，σ_d 为测距标准差，δ_H=2σ_d。
- 对称软先验：L_sym = Σ_i ρ_GM(‖v_i − S_g(v_{σ(i)})‖; κ)，ρ_GM(x;κ)=x²/(x²+κ²)（Geman–McClure），S_g 为塔身对称群元素（关于两竖直对称面的反射及 180° 旋转），高低腿时按腿分段定义。
- 共面：L_plane = Σ_f Σ_{i∈f} (n_f·v_i − d_f)²，f 为塔身面、横担面。
- 规格：L_spec = Σ_e min_k [ (b_e − b_k)²/σ_b² + (t_e − t_k)²/σ_t² ]（连续阶段用软最小值 −τ log Σ_k exp(−·/τ)，τ 退火至 0，或等价 Gumbel-Softmax）。
- 稀疏：L_sparse = Σ_{e∈E_cand} π_e，仅作用于候选杆件。
- 正则：节点附属面元、外观高频项与依附参数 s 越界惩罚。

权重示例：w_m=0.5，w_r=1.0，w_d=0.2，w_sym=0.05，w_pl=0.01，w_c=0.1，w_π=0.01。

### 4.8 优化流程

1. 阶段一（固定拓扑，约 15 000 次迭代）：优化 v、s、φ、δ 与外观，冻结 b、t，避免肢宽吸收位置误差；可同时优化 T_LC、Δt（"杆件即靶标"在线标定）。
2. 阶段二（约 10 000 次）：解冻 b、t，加入 L_spec 软项。
3. 阶段三（每 2 000 次一轮）：拓扑更新（4.9）。
4. 阶段四：规格离散吸附后固定 b、t，微调 v、φ、δ 约 3 000 次。
5. 优化器 Adam，节点学习率 1e−3 m，角度 1e−2 rad，截面 5e−4 m；位置类参数余弦退火。

### 4.9 拓扑更新与几何不变性

- 剪除：π_e < π_min（0.1）的杆件删除。
- 新增：在主材与边界构成的每个面板内，按面板语法（单斜、交叉 X、K 型、再分式、横隔）生成候选杆件，ℓ_e 初值 −2；若候选沿线的掩膜残差 ∫|O_s − M| 或激光距离残差高于阈值，激活该候选参与优化。
- 闭环塔头：先以多视轮廓与激光拟合塔头外边界闭环折线，作为边界杆件，再在其围成的面板内生成候选（边界优先）。
- 几何不变性检查：每次拓扑变更后组装三维梁（或空间铰接桁架）总刚 K，计算最小若干特征值；若出现零能模态（λ_min/λ_max < 10⁻¹⁰）或 Maxwell–Calladine 计数 3|V| − |E| − 6 > 0 的局部机构，则撤销本次删除或强制保留使机构消失的候选。

### 4.10 规格吸附

规格表 𝒮 = {(b_k, t_k)} 取 GB/T 706 热轧等边角钢（L40×3 至 L250×35）。阶段四对每根杆件取 k* = argmin_k [(b_e−b_k)²/σ_b² + (t_e−t_k)²/σ_t²]；同一对称组（由 S_g 关联）与同一面板分组内采用多数投票一致化。肢厚 t 可观测性弱，后验标准差大时以同规格肢宽常用肢厚为默认，并在置信度中体现。

### 4.11 不确定度与置信度

在收敛点 Θ̂ 处，以残差加权雅可比做 Gauss–Newton 近似：

  H ≈ Jᵀ W J + H_prior，Σ_Θ ≈ H⁻¹　　　(16)

J 为全部像素与射线残差对 Θ 的雅可比（几何部分维度约 3|V|+5|E|），W 为残差权重，H_prior 为对称、共面先验的海森。采用按杆件—节点分块的稀疏 Cholesky 或对角＋块对角近似。由此得节点协方差 Σ_{v_i}、肢宽标准差 σ_{b,e}、朝向标准差 σ_{φ,e}。

  节点置信度 c_i = exp(−√tr(Σ_{v_i}) / τ_v)
  杆件置信度 c_e = π_e · exp(−σ_{b,e}/b_e) · exp(−σ_{φ,e}/τ_φ) · min(c_i, c_j)　　　(17)

规格后验概率 P(k|e) ∝ exp(−½(b_e−b_k)²/(σ_{b,e}²+σ_b²))，输出 Top-1 规格及其概率。

### 4.12 对称破缺量

逐节点 Δ_i = ‖v_i − S_g(v_{σ(i)})‖；逐杆件二维指标 (渲染残差 r_e, 对称残差 Δ_e)。Δ_i 超阈值且置信度高时标记为高低腿、弯曲、错装或损伤候选；多期复测时，继承前期拓扑作为 G₀，输出逐杆件变化量。

### 4.13 有限元导出

每根杆件 → 三维梁单元（Timoshenko 或 Euler–Bernoulli），截面属性按规格 k* 取 A、I_u、I_v、I_t 及主轴方向（由 φ_e 确定），偏心 δ_e 以刚臂（偏心连接）形式引入；材料默认 Q235/Q355（可人工复核）；节点合并公差 1 cm；单元属性附 c_e、P(k*|e)。可导出 ANSYS APDL、OpenSees Tcl、Abaqus inp 或通用 JSON。

### 4.14 补测视点规划与带电安全壳（对应图8）

目标量：取有限元关注量 R（塔顶位移、关键杆件应力比、前 n 阶频率等）对 Θ 的灵敏度矩阵 S = ∂R/∂Θ（伴随法或有限差分），定义力学风险加权精度阵 A = Sᵀ Q S + β·diag(1 − c)，Q 为关注量权重，第二项使低置信杆件即使灵敏度小也获得一定权重。

候选视点 ξ=(p, 姿态, 相机俯仰, 激光倾角) 的预测信息 H_ξ = J_ξᵀ W_ξ J_ξ（由当前模型渲染该视点的期望像素/射线雅可比得到，不需实际采集）。目标函数：

  ξ* = argmax_ξ  [ tr( A Σ_Θ ) − tr( A (Σ_Θ⁻¹ + H_ξ)⁻¹ ) ] − λ_T·T(ξ_prev, ξ)　　　(18)

T 为飞行时间/能耗代价。多视点采用贪心序贯选择（目标对视点集合近似子模，贪心有 (1−1/e) 近似保证），每选一点按 Σ_Θ ← (Σ_Θ⁻¹ + H_ξ)⁻¹ 更新。

带电安全壳约束：以导线、跳线、绝缘子串和带电金具（由点云分类与悬链线拟合得到）为带电体集合 𝓒，按线路电压等级 U 取最小安全距离 d_s(U)（依据 DL/T 409、DL/T 1482 等规程，可配置，例如 110 kV、220 kV、500 kV 分别取不小于规程值并加飞行误差裕量 d_m），构造安全壳

  Ω_s = { p : min_{q∈𝓒} ‖p − q‖ ≥ d_s(U) + d_m + r_UAV }　　　(19)

r_UAV 为无人机外廓半径，d_m 由定位误差（RTK 水平/垂直 3σ）与风扰动估计。视点及相邻视点间的航段（离散采样）都必须位于 Ω_s 内，且与塔体最小距离 ≥ d_t（防碰撞）。不满足时，在可行域内以相机俯仰/激光倾角调整视向替代靠近，或改用仰视相机。终止条件：所有关键杆件 c_e ≥ c_min 且 tr(AΣ_Θ) 低于阈值，或补测预算用尽。

### 4.15 同步采集载荷（对应图4–图7）

1. 结构组成：快拆接口与减振挂架（4 只硅胶/钢丝绳减振器）→ 碳纤维/铝合金刚性主框架 → 激光扫描头经倾角调节机构安装于框架前部；俯视测绘相机（全局快门或机械快门，2 000 万像素级，4/3 画幅）固定于框架下部，光轴向下倾 45°～90° 可设；仰视相机（全局快门，视场 ≥ 80°）光轴斜向上 15°～60°，用于塔头内侧与横担下表面；GNSS/INS（双天线 RTK）与 IMU 固连于主框架；同步板与机载计算单元位于框架上部壳体内。
2. 倾角调节机构（对应图6）：激光头经轴承支撑在横向耳轴上，耳轴由步进电机经蜗轮蜗杆减速驱动，蜗轮蜗杆自锁保证断电保持；绝对式磁编码器直接测耳轴转角，反馈至同步板并随每帧激光数据记录；设 −30°、0°、+30° 等定位档及机械限位块；可设第二激光头对称倾斜布置，形成双倾角，扫描平面互相交叉，减少竖向重复遮挡。
3. 同步电路（对应图7）：GNSS 接收机输出 PPS 与 NMEA/时间报文 → 同步板（MCU/FPGA）以 PPS 驯服本地高稳晶振，生成相机硬触发脉冲；相机闪光同步（Strobe/曝光有效）信号回送同步板，取上升沿与下降沿中点为曝光中点时刻并打时间戳；激光雷达接受 PPS＋时间报文（或 PTP/gPTP）对齐逐点时间戳；编码器角度、IMU 数据同源打戳；机载计算单元经以太网汇总，时间同步误差目标 ≤ 10 μs。
4. 在线标定：外参 T_LC 与相机—激光时间偏移 Δt 作为 4.8 阶段一的附加参数，以杆件在影像轮廓与激光距离中的强几何对应作为天然靶标联合优化，倾角编码器读数作为外参链中的已知转角。
5. 机载计算单元：执行增量初始化、置信度估计与补测视点规划（式 18–19），把补测航点发送飞控。

## 7 替代方案

1. 面元形式：二维面元高斯（2DGS 射线—面元求交）、三维扁平高斯、每肢 P=1～4 列均可；可在肢厚方向加第二层面元表达肢厚。
2. 截面类型：不等边角钢、组合角钢（十字、T 形组合）、钢管塔圆管（此时生成环向面元）、混凝土杆；生成函数按截面轮廓替换。
3. 初始桁架图：点云节点优先法、设计模板/图纸、同类塔库检索、人工交互，均可。
4. 渲染器：基于瓦片的 α 合成光栅器、射线追踪高斯渲染，或可微体渲染；激光可按射线追踪或距离图（range image）光栅化。
5. 激光雷达：机械旋转多线、转镜式测绘级、非重复扫描式；多回波或全波形（全波形时用式 (11) 卷积波形似然代替首回波）。
6. 不确定度：拉普拉斯近似之外可用集成（多初值）、MCMC 或变分推断。
7. 规格离散化：软最小值退火、Gumbel-Softmax、分支定界或动态规划分组一致化。
8. 补测目标：A-最优（迹）之外可用 D-最优（行列式）、E-最优，或期望熵减；路径可用 TSP/子模定向求解。
9. 载荷：倾角机构可为舵机直驱＋编码器、手动分度锁定；双激光头固定不同倾角；仰视相机可由云台俯仰替代；同步可用 PTP/gPTP 代替 PPS。
10. 平台：多旋翼、垂起固定翼、系留无人机或地面/爬塔机器人搭载。
11. 有限元：空间桁架杆单元（仅辅材）＋梁单元（主材、斜材）混合；可接入静力、模态、风振时程分析。
