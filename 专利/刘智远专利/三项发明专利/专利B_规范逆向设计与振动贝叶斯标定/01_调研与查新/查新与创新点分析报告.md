## 3 权利要求 1 技术特征分解

| 特征 | 内容 |
|---|---|
| F1 | 获取由测量数据重建的输电塔杆件级桁架模型（节点坐标、杆件连接、主/斜/辅类别） |
| F2 | 由桁架模型几何自动提取设计输入：呼高、横担长度、导地线挂点数与相序布置、绝缘子串长度；按规则表由绝缘子串长与挂点布置推定电压等级，由横担/挂点相对线路走向的布置推定直线/耐张/转角塔型与转角，结合线路台账或相邻塔位得到档距与代表档距 |
| F3 | 按对称关系与面板将杆件分为截面组，以设计输入构造规范荷载组合，在强度、稳定、长细比约束下对截面组做离散规格优化 |
| F4 | 对设计输入与设计裕度的不确定性抽样，重复 F3 得到每个截面组在角钢规格档位上的离散先验分布（规范逆向设计先验） |
| F5 | 以先验模型的模态灵敏度构造 Fisher 信息矩阵，用有效独立法在主材节点中选定测点 |

| F7 | 以截面组档位（离散）、节点连接刚度系数与基础柔度（连续）为待标定参数，以 F4 先验和模态似然构造后验，采样（TMCMC 等）得到后验分布 |
| F8 | 输出带后验不确定度的标定有限元模型，并在设计荷载下做位移/应力比验算，给出超限概率 |

### 4.1 与 D1 CN117933030B

D1 由点云直接估截面尺寸后查库。区别：本发明不依赖点云对肢宽肢厚的直接分辨（ULS 点密度 100–500 pts/m² 时肢宽方向仅 1–2 点，肢厚不可测），截面信息来自“设计规范+结构动力响应”两个独立信源；并同时标定点云无法观测的连接刚度与基础柔度。D1 的直接测量值在本发明中仅可作为可选观测项并入似然，二者路线不同。

### 4.2 与 D2 L01

L01 明确材料与截面“不从点云推断，取自预定义库”，与 PTM 统一赋值同类；无振动标定。区别特征 F2–F8 全部未公开。

### 4.3 与 D3 L26/L07、D4 N1

公开了“钢桁架/输电塔 + 环境振动 OMA + 模型修正”的一般构思，L26 修正基础弹簧与节点刚度。区别：(a) 修正参数中含按对称/面板分组的离散截面档位；(b) 先验来自由点云提取设计输入后的规范逆向设计，而非均匀先验或工程师初值；(c) 初始模型来自自动重建的桁架模型。截面组参数维数高（数十组）、模态数据少（通常 4–8 阶），无信息先验时问题不适定（不同截面组合给出相同频率），规范先验正是使其可辨识的关键，这一组合未见公开。

### 4.4 与 D5 L17

L17 为正向设计：已知荷载求最轻截面，输出单一解。本发明把正向设计“反用”：荷载条件由点云推定且不确定，对其抽样多次优化，得到截面组在规格档位上的概率分布作为先验，再由振动数据更新。目的、输入与输出均不同。

### 4.5 与 D6 L08–L10

FIM/EfI 测点优化本身已公开，不作为创新点主张。本发明中测点候选集限定于主材可夹持节点，信息矩阵对截面组/连接/基础参数（而非仅模态坐标）求灵敏度，属于与 F7 配合的从属特征。

### 4.6 与 D7 PTM

PTM 提供 F1，截面按主/斜/辅统一赋值（L220×22/L140×12/L90×8），只做静力线弹性；其 V-D 节把“基于传感器的模型修正”列为未来工作，仅为方向性陈述，未公开任何具体手段。本发明给出了实现该方向的具体技术方案。

### 4.7 硬件（振动采集节点）

L07、L11–L13、L25 公开了太阳能无线加速度计、GPS-PPS 同步节点、GNSS+加速度一体化传感器。区别：节点通过与角钢肢背 90° 外角配合的 V 形夹块和偏心凸轮/螺杆夹紧机构无损夹持于主材，夹块上设定向基准面使传感轴与主材肢面、塔身轴线保持已知对齐，配合节点编号与有限元节点的绑定。V 形夹块单独属常规夹具，创造性主要依赖与方法的配合，建议作为装置独立权利要求时加入“定向基准+GNSS PPS 时间戳+节点/有限元节点绑定”组合，风险中等。

## 5 新颖性与创造性初步分析

- 新颖性：F2、F4 及 F2–F4–F7 的组合在已检文献中均未公开，权利要求 1 具备新颖性。
- 创造性：以 D1 或 D2 为最接近现有技术，区别特征为 F2–F8。实际解决的技术问题：无竣工图条件下，测量数据不能分辨的截面、连接与基础参数如何获得可信值及不确定度。D3/D4 给出振动修正的一般启示，但未启示把规范设计反用为离散先验；D5 只给出正向设计。将 D1/D2+D3+D5 简单叠加只能得到“点云模型+振动修正”或“点云模型+正向设计”，得不到“由点云推设计输入→多次逆向设计成先验→振动更新离散截面组”的链条，且该链条带来可辨识性提升（仿真：截面组识别率 【待填:截面组识别率_本发明】 vs 仅振动修正 【待填:截面组识别率_仅振动】）。创造性有较好依据。
- 主要风险：审查员可能认为 F4“抽样+优化”为常规不确定性传播。应对：在权 1 中写明先验是“截面组在规格档位上的离散分布”，并在从属权利要求中写明设计裕度分布、标准化档位、对称分组约束，说明书给出无先验时的不可辨识例。

## 6 创新点归纳

1. 设计输入几何反推：由桁架模型几何+规则表推定电压等级、塔型、转角、档距，替代缺失的竣工图（F2）。
2. 规范逆向设计离散先验：对不确定设计输入与设计裕度抽样，多次离散截面优化，统计成截面组规格档位分布（F3–F4）。
3. 离散-连续混合贝叶斯标定：截面组档位、节点连接刚度、基础柔度同时作为参数，先验+SSI-COV 模态似然，TMCMC 或代理模型求后验（F7）。
4. 面向标定参数的测点优化与夹持式同步节点：FIM 对待标定参数求灵敏度，有效独立法在主材可夹持节点中选点；V 形夹块+定向基准+GNSS PPS 的节点（F5–F6、装置）。
5. 带后验不确定度的规范验算，输出超限概率而非单值结论（F8）。
