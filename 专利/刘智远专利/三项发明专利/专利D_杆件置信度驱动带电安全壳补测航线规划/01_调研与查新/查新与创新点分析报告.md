# 专利D 查新与创新点分析报告

发明名称：一种基于杆件级置信度与结构灵敏度的输电塔无人机补测视点规划方法、系统及机载实时评估装置

## 1. 背景与定位

论文 PTM（clean_dump.txt）以 ULS 点云“节点优先”重建 LoD3 桁架并做有限元变形分析，但存在：点稀/遮挡导致局部杆件缺失（Fig.12 b-I）、无逐杆件可信度输出、无补测机制、截面统一假设。前期评估（00_候选专利池评估与两项定稿.md，P1/C5）认为“NBV/覆盖规划文献与巡检航线专利多，单独成案创造性偏弱，并入A从属”。本报告按用户要求单独成案，正面评估如下。

## 3. 创造性正面评估

单项特征均有公开：信息增益NBV（D1、D2、D6）、子模贪心（D2）、TSP航线（D6）、安全距离（D8）。若独立权利要求只写“置信度驱动NBV+安全距离”，将被 D1+D2+D8 组合评价为显而易见，结论与前期一致。

可成立创造性的组合（独立权利要求落点）：
1. 结构灵敏度加权的杆件置信度信息增益：置信度为逐杆件量（点数、视角覆盖、对称一致性三态：一致/可补/破缺），权重为该杆件截面与位置不确定性对塔顶位移、关键杆件应力比、前若干阶频率的有限元灵敏度。D1~D6 的增益均为几何覆盖或地图熵，无结构响应维度；且“破缺”态（真实不对称，如高低腿、损伤）被排除出对称补全、反而提升补测优先级，属现有技术未给出的启示。
2. 带电安全壳约束：按电压等级取 DL/T 409 最小安全距离，叠加 GNSS/RTK 定位误差、飞控跟踪误差、风扰漂移与机体外廓半径构成扩张体，候选视点仅在壳外采样，航段离散点逐点校核。D8 只给标量距离，无“壳外采样+航段校核”的规划机制。
3. 机上闭环停止判据：机载装置对新到点云增量更新受影响杆件的置信度与结构加权风险，当结构加权剩余不确定度低于阈值、或所有灵敏度前K杆件脱离“可补”态即停止，并在线删减剩余视点重排航线。D5 有在线质量评估但停止判据为表面质量。

技术效果：以结构风险而非几何覆盖分配飞行资源，同等航时下塔顶位移/应力比预测不确定度下降【待填:不确定度下降比例】，补测视点数减少【待填:视点减少比例】，安全壳违规航段为0。

结论：三者组合具备单独成案的新颖性与创造性的合理基础，但创造性强度中等，审查中可能被以 D1+D2+D8+通用FE灵敏度 组合质疑；需在说明书中充分记载协同效果（灵敏度权重改变视点排序、破缺态处理、停止判据节省航时）与对比数据。

## 4. 与专利A的抵触申请风险及建议

风险：A 权利要求13已记载“有限元灵敏度矩阵×杆件置信度构造风险加权矩阵、信息增益减飞行代价、序贯贪心”，权利要求14记载“按电压等级最小安全距离+定位误差裕量+外廓半径构成带电安全壳”。若A先于D申请，A的说明书构成D的抵触申请（专利法第22条第2款），D中与A相同的技术方案丧失新颖性；若同日申请且权利要求相同，构成第9条重复授权，需二选一。

建议：
1. A 与 D 同日递交（同一天，不同申请号），避免A成为D的抵触申请；同日申请仅需避免“同样的发明创造”。
2. 收窄或删除A权利要求13、14：建议A只保留“以A的拉普拉斯协方差为输入、引用补测”的一句话从属，不写安全壳细节；或保留但措辞限定于“由所述拉普拉斯近似协方差”且无三态、无停止判据。
3. D 的独立权利要求不依赖高斯泼溅：置信度由点云统计（点数、视角覆盖、对称三态）计算，适用于 PTM 类任意桁架重建结果；说明书不披露A的面元高斯生成、无回波负证据等内容，仅称“任意杆件级桁架重建方法”。
4. D 的信息增益采用逐杆件置信度形式（非A的 tr(AΣ) 矩阵形式），与A在表述和技术特征上明确区别。
5. 若D后于A申请，须确保独立权利要求含三态判别与机上停止判据这两项A未记载的特征。
