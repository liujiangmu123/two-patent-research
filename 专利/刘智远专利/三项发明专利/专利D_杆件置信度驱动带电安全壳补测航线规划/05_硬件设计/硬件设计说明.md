# 专利D 机载实时评估装置 硬件设计说明

## 1 定位与区别
装置重点是“机上计算 + 工频电场感知 + 飞控闭环”：机上完成增量重建、杆件置信度三态评估、补测视点重规划，并在航点下发前做安全壳越界校验。装置不含倾角机构、双相机和 PPS 同步板，与专利A的同步采集载荷结构不同；激光雷达沿用机上已有传感器，只接入其数据流。

## 3 尺寸、质量、功耗
- 主体外壳 150×110×50 mm；含绝缘桅杆与电场传感头总包络 189×130×240 mm（FreeCAD 构建记录）。
- 结构件估算质量 930 g（构建记录按材料密度计算，含壳体、板卡、桅杆、天线）；加线缆和元器件余量，整机按 ≤1.1 kg 设计。
- 功耗：计算 15 W 典型 / 25 W 峰值，接口与 ADC 2 W，4G 3 W，风扇 1 W；合计典型 21 W，峰值 31 W。

## 4 接口
- 激光雷达：M12 航插，千兆以太网 + PPS 输入（只接收时间戳，不做多相机同步）。
- 飞控：UART 921600 bps，MAVLink 2（MISSION_ITEM_INT / SET_POSITION_TARGET）或 DJI PSDK 航点任务。
- 电源：XT30，6S 电池直供。
- 回传：4G 天线 ×2（SMA）。

## 5 时延预算（单次补测决策）
| 环节 | 预算 |
|---|---|
| 点云接收与位姿对齐（1 s 片段） | 50 ms |
| 增量重建与杆件骨架匹配 | 300 ms |
| 杆件置信度三态更新 | 50 ms |
| 灵敏度查表加权（离线预计算 FE 灵敏度） | 5 ms |
| 候选视点生成与安全壳筛选 | 100 ms |
| 子模贪心 + TSP 局部重排 | 200 ms |
| MAVLink 航点下发与确认 | 50 ms |
| 合计 | ≤ 755 ms（<1 s 决策周期） |

电场冗余链路独立于上述流程：ADC 采样 → MCU 判阈 → 飞控指令 ≤ 20 ms。
