# 说明书摘要

本发明公开一种基于杆件级桁架有限元影响矩阵的输电塔InSAR形变解耦与基础差异沉降反演方法、系统及塔材夹持式角反射器。方法以点云重建得到的杆件级桁架模型建立有限元模型，求解各塔腿支座竖向、水平单位位移及单位温度场工况，组成影响矩阵；以桁架几何计算逐杆件日照遮挡温升作为热基函数；经散射体仿真将永久散射体点关联至杆件，按升降轨视线向矢量把影响矩阵投影为观测算子；联合升降轨时序形变求解各塔腿基础位移与温度系数，再正演塔体倾斜与杆件应力并分级预警。角反射器以L形外夹块和内压板夹持角钢主材，经悬臂托架、方位转台和双向横梁安装升、降轨两只三面角反射器，相位中心相对夹持基准球的偏置由结构确定。本发明在塔脚点云缺失时仍可反演基础差异沉降，并把热胀从沉降中分离出来。
