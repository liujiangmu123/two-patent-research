## 必读
- 本件 `00_README.md`
- `10_审查与迭代\` 下全部文件（各轮审查意见、附图审查、形式审查、数值一致性审计、保护范围与答复预案、未关闭问题清单）
- `06_申请文件\修改说明.md`、`_校验报告.txt`
- `03_仿真验证\独立复核\独立复核报告.md`（上一次中断前已写）

## 步骤
1. 核对历史问题是否已关闭，未关闭的逐条修改：
   - 第1轮 S1～S5、G1～G9；
   - 形式审查第2轮 1～3；
   - 数值审计第2轮 1～9；
   - 附图审查各项。

   修改范围：改文字只改 `07_脚本\patent_text.js`、`patent_desc.js`、`roles.js`，以及 `05_附图\numerals*.json` 的名称，做到一号一名、两张表统一。需要改图形的只记录，不改。
2. 落实《保护范围与答复预案》中 B1～B8 写入说明书的内容。不得引入说明书没有支持的内容。
3. 独立复核：
   - 检查独立复核报告的结论；
   - 偏差 >5% 的项查清原因，修正主仿真或注明口径；
   - 仿真验证报告补一节"独立复核"，再转 docx/pdf。
4. 依次重跑生成链：
   - `$env:NODE_PATH=(npm root -g); node 07_脚本/build_patent_docx.js`
   - `check_patent.py`，必须全部通过，TODO 为 0
   - `docx2pdf.ps1 -Dir 06_申请文件`

   之后用 PyMuPDF 抽查 PDF 的页数、页眉和附图页。同步更新 `修改说明.md/.docx/.pdf`、`08_技术交底书\技术交底书.md` 及其 docx/pdf，以及 `00_README.md` 中的状态行。
5. 自我循环（最多 3 轮）：每轮以审查员视角写 `10_审查与迭代\第N轮自审.md`（N 从 3 起），逐条修改后重跑生成链，直到没有"严重"和"一般"问题。审查内容：
   - 新颖性和创造性，对照 D1 CN112692317A、D2 KR20120066304A、D3 CZ278098B6、E1 EP2597317A1、E4 JP2008185185A；
   - 第26条第3、4款；
   - 修改超范围；
   - 形式；
   - 数值。
6. 组合边界：P2～P5 的独立权利要求会单独保护卡盘复压、ΔL 测量、试验台结构、阀块结构。P1 中这些内容保留为从属或附带的独立权利要求即可；不要扩写成与它们相同的范围。
7. 刷新 `未关闭问题清单.md`，只留需申请人确认的事项。更新 `..\00_专利组合总览.md` 第 4 节 P1 行。
