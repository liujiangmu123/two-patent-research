主要设计结论：

1. 双腔预压锁闭在刚度和热漂移两项上都优于单腔锁闭，结论对 β=800～1600 MPa、km=50～200 N/µm、x=20～130 mm 全部成立（c02.随beta/随km/随顶紧位置x）。
2. 锁闭后推力仍会变化，主要原因按量级排序：工件热伸长（每 6.6 µm 越带一次）> 油温漂移（0.68 K 越带）> 活塞内泄漏（141 s 越带）。因此"越带双向回复"是必要的，不是可选项。
3. 本方案的能耗主要不在尾座，而在卡盘：回转接头泄漏占 M2 保压耗油的 84%。卡盘"回中位卸掉回转接头压力 + 周期复压"是节能量的主要来源，尾座锁闭贡献的是"推力恒定"和"刚度"。
4. 方案乙（V3+阻尼孔 22 微泄）即使 Ø0.1 mm 阻尼孔，降半带宽也只需 35 ms，与座阀开关时间同量级，可控性差。推荐方案甲。
5. 基准参数有 5 处需要修订（蓄能器压力窗口与 F0 上限、溢流阀与允许油缸力、电机功率、细长轴顶紧力、内泄漏实测），见 `基准参数修订建议.md`。

## 1 系统原理

### 1.1 回路组成（图1）

- 动力源：油箱 1、吸油过滤器 2、定量泵 3、电动机 4、溢流阀 5、电磁卸荷阀 6、单向阀 7、蓄能器 8、压力传感器 S0（9）。新增隔离座阀 V0（29），位于蓄能器出口与两个换向滑阀 11、18 的 P 口之间。
- 卡盘回路：卡盘减压阀 10 → 卡盘换向阀 11（Y 型中位）→ 回转接头 15 → 回转油缸 12（内置液控单向阀 13）；压力传感器 S1（14）。有杆腔进油、活塞杆缩回夹紧。
- 尾座回路：尾座换向阀 18（Y 型中位）A 口经尾座减压阀 R1（16）接第一锁闭座阀 V1（19）→ 无杆腔；B 口接第二锁闭座阀 V2（20）→ 有杆腔；预压减压阀 R2（17）经预压座阀 V4（23）接有杆腔；方案乙另设微泄座阀 V3（21）和阻尼孔 22（无杆腔至油箱）。两腔压力传感器 S2（24）、S3（25），油温传感器 T1（30）。19～25、30 集成在锁闭阀块 55 上，阀块直装尾座缸 26。
- 控制：PLC 27，触摸屏/数控接口 28。

### 1.3 双腔预压锁闭的推力方程

锁闭后取活塞向工件方向位移 du、工件热伸长 dδ、油温变化 dT、活塞内泄漏净转移体积 dVq（1→2）。线性化后：

```
dp1 = β/V1 · (−A1·du + α·V1·dT − dVq)
dp2 = β/V2 · ( A2·du + α·V2·dT + dVq)
dF  = A1·dp1 − A2·dp2 = km·(du + dδ)
=> dF = km/(k1+k2+km) · [ (k1+k2)·dδ + β·α·dT·(A1−A2) − β·dVq·(A1/V1 + A2/V2) ]
其中 k1 = β·A1²/V1，k2 = β·A2²/V2，单腔锁闭（有杆腔通油箱）时 k2=0、A2 项为 0。
```

由式可得：

- 刚度：K=(k1+k2)·km/(k1+k2+km)。有杆腔油柱与无杆腔油柱并联，提高液压刚度。
- 油温漂移：两腔油液同时膨胀，推力只按面积差 A1−A2=Ar（活塞杆面积 962 mm²）变化，而单腔时按 A1（3117 mm²）变化，源力比 0.31；再乘以 km/(Σk+km) 后得 440/1746=0.25。
- 预压 p_pre 本身不出现在线性方程中。它的作用是保证 p2 在油温下降、工件回缩时不跌到气体析出压力以下，使 k2 和 β 保持有效（若有杆腔接油箱，k2=0，等同单腔）。这是权利要求中"高于回油压力"的物理依据。
- 代价：内泄漏同时降低 p1、提高 p2，泄漏对推力的灵敏度由 10.7 增至 17.2 kN/cm³。所以必须用零泄漏座阀，并接受"泄漏越带后回复"。

## 3 计算书

### 3.1 缸径与压力（c01）

- 尾座缸 A1=3117 mm²，A2=2155 mm²，Ar=962 mm²，A1/A2=1.446。
- p1_set=(F0+p_pre·A2)/A1：F0=2000/6000/12000 N 时为 1.679/2.962/4.887 MPa。
- 减压阀压差：F0=12000 N 时 p1_set=4.887 MPa，蓄能器最低 5.0 MPa，余量只有 0.11 MPa；按减压阀需要 0.5 MPa 压差（假设）计，现窗口只能保证 F0≤10.79 kN。若保持 F0 上限 12 kN，pmin 应提高到 5.39 MPa 以上（c01.减压阀压差裕量）。
- 最大力：溢流阀 6.5 MPa 全压作用于无杆腔为 20.26 kN，超过允许最大油缸力 18 kN。必须由 R1 限压（R1 最高设定不超过 6.81 MPa 对应 18 kN，实际限位到 5.0 MPa），或把溢流阀降到 5.77 MPa 以下（c01.尾座最大力）。
- 活塞杆稳定性：Ø35，计算长度 300 mm（假设）、长度系数 2，Fcr=416 kN，对 18 kN 安全系数 23。
- 卡盘：A2=7363 mm²，额定 2.0 MPa 拉力 14.7 kN，使用范围 3.6～16.2 kN。
- 流量：尾座前进 5 mm/s、0.94 L/min；卡盘 1.2 s 夹紧需 7.36 L/min，大于泵有效流量 5.22 L/min，由蓄能器补充（3.4 节）。

### 3.3 热漂移与工件热伸长（c02）

- 油温漂移：单腔 1746 N/K，双腔 440 N/K。±5% 带（300 N）对应油温变化：单腔 0.17 K，双腔 0.68 K。
- 越带时间（油温速率 0.02～0.2 K/min）：单腔 0.86～8.6 min，双腔 3.4～34 min。
- 日变化 5 K：单腔推力变化 8.7 kN（大于 F0），双腔 2.2 kN。
- 工件热伸长：Ø30×500、10 K 伸长 57.5 µm，单腔推力增 1.92 kN、双腔增 2.62 kN；Ø20×800、15 K 伸长 138 µm，增 4.60/6.28 kN。双腔每 6.6 µm 伸长就越上限一次。
- 细长轴稳定性：Ø20×800 两端铰支 Fcr≈24.9 kN，F0=6 kN 时弯曲放大 1.32，不回复时升到 1.74～1.97。此类工件应降低 F0（建议 F0≤0.3·Fcr≈7.5 kN 且同时越带回复）。

结论：双腔刚度高，所以对热伸长更"敏感"。本发明不是靠锁闭本身容纳热伸长，而是锁闭提供刚度，越带回复负责推力恒定，两者分工。

### 3.4 蓄能器（c03、c04）

- 1.0 L、p0=4.5 MPa、5.0～6.0 MPa：可用容积 等温 147.8 cm³，绝热 111.5 cm³（与基准 150/113 一致）；0℃/40℃ 时 106/117 cm³。
- p0/pmin=0.90，处于常用经验范围（0.6～0.9）上限；40℃ 时 p0 升到 4.81 MPa，仍低于 pmin。若按修订建议把 pmin 提高到 5.5 MPa，p0 可保持 4.5 MPa。
- 卡盘 1.2 s 夹紧需 147 cm³，泵 1.2 s 供 104 cm³，需蓄能器补 43 cm³ < 111 cm³，满足；仅靠泵需 1.69 s。
- 充液：pmin→pmax 1.28 s；首次从空充到 pmax 约 2.8 s。

## 4 锁闭阀块 55 设计

- 外形约 120×80×70（长×宽×高），材料 45 钢调质发黑或 6061-T6（压力 ≤7 MPa，铝块可用；与缸体热膨胀差需核对密封）。
- 安装：底面直接贴合尾座缸 26 缸体铣出的安装面，4×M8 螺钉；两腔油口在接合面用 O 形圈端面密封，锁闭腔内无软管、无管接头。
- 插装腔：V1、V2、V4（方案乙加 V3）四个 Sun T-162A 两通腔；S2、S3 用 G1/4 传感器口，紧贴座阀腔侧；T1 插入无杆腔流道旁的 M10 盲孔（与油液直接接触更好，需选带护套的型号）。
- 流道：尾座最大流量按 1 L/min，v≤2 m/s 需 Ø3.3 mm，取 Ø6 mm（流速 0.59 m/s）。每腔阀块内流道约 5.1 cm³，加座阀腔与传感器腔后控制在基准 15 cm³ 以内（c04.锁闭阀块55流道）。
- 外部油口：A（来自 R1）、B（来自 18 的 B 口）、P_pre（来自 R2）、T（方案乙泄油），均 G1/4。
- 阻尼孔 22：方案乙用。按 c04.阻尼孔表，Ø0.1/0.15/0.2/0.3 mm 时推力降速率 4.2/9.5/16.9/38.0 kN/s，降半带宽需 35/16/8.9/3.9 ms。建议 Ø0.1 mm 双级串联并前置 10 µm 保护滤网。
- 排气：阀块最高点设排气螺塞，首次注油必须排气（空气会使 β 远低于 1200 MPa）。

## 5 控制逻辑与参数

### 5.1 状态机（对应图5 S1～S8）

1. S1：V0 开、11 夹紧位，S1≥pc 且到位开关 32 有信号，延时 0.2 s 后 11 回中位，记 Chuck_OK。
2. S2：Chuck_OK 前提下，18 前进位、V1、V2 开；S2 达 p1_set 且位移稳定 0.3 s 后，18 回中位、V2 关、V4 开 0.3 s 建立 p_pre，再关 V4。
3. S3：关 V1、V2、V4、V0；S0≥pmax 后停泵。
4. S4：每 10 ms 采样，F=p1·A1−p2·A2，一阶低通 τ=0.2 s（假设）。
5. S5：F<F_L 持续 0.5 s → 开 V0、18 前进位、V1、V4；|F−F0|≤0.02F0 持续 0.1 s 后全关；超时 2 s 报警。
6. S6：F>F_H 持续 0.5 s → 同 S5（方案甲，R1、R2 经二次侧溢流泄压）；方案乙为 V3 脉冲 20 ms、间隔 0.2 s 多次，直至进带。
7. 安全：F>F_safe=7500 N 或 F<0.5F0 立即开 V1、V4 回复并报警，若 2 s 内不能回复则请求数控暂停进给、停主轴。
8. S7/S8：加工结束信号后 18 后退位、V1、V2 开，退到位后才允许卡盘松开。

并行任务：蓄能器 S0<5.0 MPa 启泵、>6.0 MPa 停泵（仅 V0 开启或动作期间才需要）；卡盘每 60 s 复压 0.5 s（假设），S1<p_min(n) 报警。

### 5.2 参数表（c04.控制参数）

| 参数 | 值 | 说明 |
|---|---|---|
| F0 / δ | 6000 N / 0.05 | 推力带 5700～6300 N |
| F_safe | 7500 N | 1.25F0 |
| p1_set / p_pre | 2.962 / 1.5 MPa | R1、R2 设定 |
| R1 最高允许设定 | 6.81 MPa | 对应 18 kN（p2=p_pre），实际机械限位到 5.0 |
| 越带确认 / 回复保持 / 超时 | 0.5 / 0.3 / 2.0 s | 假设，试验整定 |
| 泄漏诊断阈值 | 回复间隔 < 35 s | 计算间隔 141.5 s 的 1/4，对应内泄 4 倍；统计前用 T1 扣除热漂移 |
| 蓄能器启/停泵 | 5.0 / 6.0 MPa | 建议修订为 5.5 / 6.5 |
| 卡盘复压 | 60 s / 0.5 s | 假设 |
| 推力测量误差 | RSS 95 N，最坏 132 N | 2 只 0.25%FS×10 MPa 传感器，占半带宽 32% |

测量误差占半带宽 32%，δ 不宜取到 0.02（±120 N）以下，除非换 0.1%FS 传感器或缩小量程到 0～6 MPa。静摩擦 150 N（2.5% F0）使 F 计算值与顶尖实际力存在偏差，用试验台推力传感器 49 标定后作为常数扣除。

### 5.3 工件伸长估算（从属权利要求 7）

ΔF_total=F−F_lock（F_lock 为最近一次锁闭时的推力），ΔF_oil=c_T·ΔT1（c_T 为标定的油温系数，理论 440 N/K），ΔL=(ΔF_total−ΔF_oil)/K（K 为标定刚度，理论 45.5 N/µm）。每次回复后累加，输出给数控系统 28 作补偿参考。误差：推力 95 N 对应 2.1 µm；油温 0.05 K 对应 22 N、0.5 µm；K 误差按 ±20% 计入。

## 8 安全设计

- 断电/急停：所有座阀常闭，断电即锁闭保持顶紧与夹紧（失电安全）；泵停、卸荷阀 6 开。
- 超压：溢流阀 5 限系统压力；R1 设定机械限位，避免尾座力超过 18 kN（基准溢流阀 6.5 MPa 下全压推力 20.3 kN 超限，必须处理）。
- 有杆腔：p_pre 由 R2 二次侧溢流限压，锁闭期间若 p2 因温升超过 R2 设定，下次回复时自动泄回。建议在有杆腔加一只小型安全溢流阀（设定 3.5 MPa，假设），防止 V2、V4 同时故障时温升憋压。
- 联锁：卡盘压力未确认，尾座不得前进；尾座未退到位，卡盘不得松开；推力越安全限或泄漏报警时请求停主轴。
- 试验台：防护门 58 打开时伺服 47 断使能、泵禁止启动；蓄能器设截止泄压阀，维修前泄压；楔块加载设机械限位与力限 20 kN。
- 蓄能器属压力容器部件，按厂家要求充氮、定期检查 p0。
